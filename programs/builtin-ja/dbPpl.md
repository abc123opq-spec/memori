器具が限られた初心者向けの、ダンベルだけで行うプッシュ・プル・レッグ（Push/Pull/Legs）のルーティンです。全種目をダブルプログレッションで進めます（12回まで伸ばしたら重量を上げます）。ダンベルとベンチ、懸垂バーしかないときに実用的です。

<!-- more -->

## 成り立ちと考え方

Redditのユーザー[/u/gregariousHermit](https://old.reddit.com/r/Fitness/comments/2e79y4/dumbbell_ppl_proposed_alternative_to_dumbbell/)が、r/Fitnessのwikiに載っていたDumbbell Stopgapルーティンの代案として作りました。自宅、ホテルのジム、設備の乏しい商業ジムなど、ダンベルしか使えない初心者は多くいます。そうした人にも、実績のある原則に沿った、構造化されたルーティンが必要だという考えから生まれました。

考え方は単純です。定評のあるスプリット（プッシュ・プル・レッグ）をダンベルで行い、ダブルプログレッションで着実に伸ばします。バーベルのプログラムを長期にわたって置き換えるものではありませんが、バーベルが使えないときの堅実な出発点になります。

## 向いている人

- **経験**：まったくの初心者（トレーニング歴0〜12か月）
- **前提**：特にありません。懸垂がまだできない場合は、ネガティブ懸垂から始めてください。
- **主な目的**：筋肥大と、ある程度の筋力向上
- **向いている場面**：ダンベルしかない人、ホテルのジムを使う出張や旅行中の人、バーベルのない自宅ジムのリフター
- **増量・減量・維持**：どの時期にも使えます。ただし、筋肉を最も大きくできるのは摂取カロリーが消費を上回っているときです。

## メリットとデメリット

**メリット**
- 必要なのはダンベル、ベンチ、懸垂バーだけです。バーベル、ケーブル、マシンは要りません。
- 単純なダブルプログレッションで、いつ重量を上げるか迷いません。
- 1回のワークアウトは5種目だけなので、短く集中して終えられます。
- 日ごとに鍛える筋群が違うので、PPLスプリットは週4〜6日で行えます。回復の時間も十分に取れます。
- 水平方向のプッシュ、垂直方向のプッシュ、水平方向のプル、垂直方向のプル、スクワット、ヒンジ、アイソレーション種目と、主な動作パターンをすべて網羅しています。

**デメリット**
- [{Goblet Squat}]が最初に停滞します。ほかの種目より先に、手持ちの最も重いダンベルが上限になり、下半身の伸びが頭打ちになります。
- 三角筋中部のアイソレーション種目がありません。肩は[{Arnold Press}]と[{Reverse Fly}]で鍛えますが、三角筋中部は直接鍛えません。
- ハムストリングスのアイソレーション種目がありません。[{Single Leg Deadlift}]と[{Lunge, Dumbbell}]はハムストリングスを使いますが、単独では鍛えません。
- プログレッシブオーバーロードが、ダンベルの重量の刻み（多くは2.5kg刻み）に制限されます。三角筋後部や上腕二頭筋のようなアイソレーション種目には、大きすぎることがあります。

## プログラムの構成

- **スプリット**：プッシュ・プル・レッグ（PPL）
- **ピリオダイゼーション**：ダブルプログレッション（12回まで伸ばしてから、重量を上げる）
- **スケジュール**：3日サイクルの固定を繰り返します。最低でも週3日（プッシュ・プル・レッグ）、最大で週6日（プッシュ・プル・レッグ・プッシュ・プル・レッグ）まで、休み1日で行えます。週6日なら各筋群が週2回刺激されます。初心者の筋肥大には、これが最適です。アプリ上の日名は英語で、Push Day、Pull Day、Legs Dayです。
- 体幹の種目（[{Hanging Leg Raise}]）は、プッシュの日とレッグの日に入っています。

## 種目の選び方と理由

**プッシュの日** は、胸、肩、上腕三頭筋を鍛えます。
- [{Bench Press, Dumbbell}]：水平方向のプッシュの主種目で、胸の筋量とプレスの筋力をつけます。
- [{Incline Chest Fly}]：インクラインの角度で、可動域を深くとって胸を伸ばし、大胸筋の上部の線維を重点的に刺激します。
- [{Arnold Press}]：回旋の動きで三角筋の3つの頭すべてに効き、標準的なプレスより肩を広く鍛えられます。
- [{Triceps Extension}]：上腕三頭筋の長頭をアイソレーション種目で鍛えます。プレスの種目では、長頭は十分には鍛えられません。
- [{Hanging Leg Raise}]：体幹を直接鍛えます。

**プルの日** は、背中、三角筋後部、僧帽筋、上腕二頭筋を鍛えます。
- [{Pull Up}]：垂直方向のプルで、広背筋と背中全体の幅をつくります。このプログラムで唯一の自重種目です。
- [{Bent Over Row, Dumbbell}]：水平方向のプルで、背中の中部の厚みと広背筋を鍛えます。
- [{Reverse Fly}]：三角筋後部をアイソレーション種目で鍛えます。ロウと懸垂だけでは刺激が足りません。
- [{Shrug}]：僧帽筋の上部をアイソレーション種目で鍛えます。
- [{Bicep Curl}]：上腕二頭筋をアイソレーション種目で鍛えます。ロウと懸垂でも使われますが、それだけでは発達が十分ではありません。

**レッグの日** は、大腿四頭筋、大殿筋、ハムストリングス、ふくらはぎを鍛えます。
- [{Goblet Squat}]：大腿四頭筋と大殿筋の主種目です。前に持つ姿勢が、体幹にも負荷をかけます。
- [{Lunge, Dumbbell}]：片脚ずつ行う動きで、左右を別々に鍛え、バランスも整えます。
- [{Single Leg Deadlift}]：ヒップヒンジの動きで、ハムストリングスと大殿筋を鍛え、片脚の安定性も高めます。
- [{Standing Calf Raise}]：ふくらはぎを直接鍛えます。
- [{Hanging Leg Raise}]：体幹の種目を追加します。

## セットとレップの構成

全種目、**12回を上限とする3セット** です。各セットで、良いフォームでできるだけ多くのレップを行いますが、それ以上できても12回で止めます。

この「12回まで×3セット」は、筋肥大の範囲（6〜12回）にしっかり収まります。上限を12回にしているのは、筋肉を大きくするのに十分な重さを使うためです。12回が楽なら、重量を増やしてください。

AMRAPセット、%、RPEの目標はありません。単純にしてあるのは意図的です。初心者に必要なのは、複雑なプログラム変数ではなく、フォームと一貫した努力です。

## プログレッシブオーバーロード

**重量の増やし方**：ある種目で3セットすべてを12回で完了したら、次のワークアウトで重量を1段階上げます（コンパウンドもアイソレーション種目も2.5kgずつ（kg 表記では 2.5kg にそろえています））。

**何が進歩か**：重量を増やさなくても、ワークアウトごとにレップが増えれば進歩です。10回×3セットから11回×3セットになれば、プログラムが機能しています。

**ディロードのきっかけ**：ある種目で、合計レップが3回連続のワークアウトで増えなかった場合は、その種目の重量を2段階下げて、そこから戻していきます。停滞した種目だけが対象です。ほかの種目は通常どおり進めます。

## どのくらい続けるか・次は何か

進歩が続くかぎり、このプログラムを続けてください。ほとんどの初心者で、目安は **3〜6か月** です。次へ移るサインは次のとおりです。

- 複数の種目（とくに[{Goblet Squat}]）で、ダンベルの重量が上限に達し続けている
- 多くの種目で停滞し、ディロードが頻繁になっている
- バーベルが使え、もっと速く筋力を伸ばしたい

**移行先**：バーベルが使えるようになったら、[Basic Beginner Routine](/programs/basicBeginner)、[GZCLP](/programs/gzclp)、[5/3/1 for Beginners](/programs/the5314b)のような、バーベルの初心者向けプログラムに切り替えます。これらは、下半身の種目で増量幅を大きくでき、全体の筋力もより速く伸びます。

## 必要な器具

- **重量を変えられるダンベル**（または、軽いものから重いものまでそろったダンベル）。固定重量のダンベル1組だけでは使えません。重量を少しずつ増やせることが必要です。
- **ベンチ**：角度を変えられるもの（フラットとインクライン）が理想です。フラットベンチでも行えますが、その場合は[{Incline Chest Fly}]をフラットの[{Chest Fly}]に替えます。
- **懸垂バー**：ドアフレームに取り付けるタイプで十分です。バーがまったくない場合は、丈夫なテーブルの縁を使った[{Inverted Row}]で代用します。

バーベル、ケーブルマシン、プレートを付けるマシンは不要です。

## 休憩時間

全セットの間で **90秒** です。ダンベルの重量なら十分に回復でき、ワークアウトも短く済みます。

## 開始重量の決め方

種目ごとに、**手持ちの最も軽いダンベル** から始めて、少しずつ上げていきます。これは元のプログラムのとおりで、作者は軽く始めることをはっきり勧めています。

ほとんどの初心者の目安は次のとおりです。
- **コンパウンドのプレス**（[{Bench Press, Dumbbell}]、[{Arnold Press}]）：片手7.5〜12.5kg
- **アイソレーション種目**（[{Incline Chest Fly}]、[{Reverse Fly}]、[{Bicep Curl}]、[{Triceps Extension}]）：片手5〜10kg
- **下半身**（[{Goblet Squat}]、[{Lunge, Dumbbell}]、[{Single Leg Deadlift}]）：片手10〜15kg
- **シュラッグ**：片手10〜17.5kg
- **懸垂とハンギングレッグレイズ**：最初は自重だけで行います。

最初のワークアウトで12回が楽だったなら、軽すぎたということです。問題ありません。最初の数回で、すぐに重量を足せます。

## よくある変更

- **懸垂ができない場合**：ネガティブ懸垂から始めます（ジャンプして上の位置に上がり、3〜5秒かけてゆっくり下ろします）。または、目標のレップをもっと多くのセットに分けます（たとえば、4回×3セットのかわりに2回×6セット）。
- **インクラインベンチがない場合**：[{Incline Chest Fly}]をフラットの[{Chest Fly}]に替えます。
- **ゴブレットスクワットが上限に達した場合**：最も重いダンベルに届いたら、[{Goblet Squat}]を[{Bulgarian Split Squat}]または[{Pistol Squat}]に替えます。軽い重量のままプログレッションを続けられます。
- **ふくらはぎをもっと鍛えたい場合**：[{Standing Calf Raise}]を、段差やプレートなどの高い場所に乗って行い、可動域を広くとります。重量が楽になったら、片脚のカーフレイズに切り替えます。
- **サイドレイズを足す場合**：このプログラムには、三角筋中部を直接鍛える種目がありません。プッシュの日に[{Lateral Raise}]を足すのは、よくある妥当な追加です。

### ダンベルだけで筋肉をつけられますか？

つけられます。とくに初心者のうちはそうです。ダンベルP/P/Lは、ダンベル、ベンチ、懸垂バーだけで、主な動作パターンをすべて網羅しています。3〜6か月は順調に伸びます。そのあと、下半身をさらに伸ばすには、バーベルが必要になるかもしれません。

### ダンベルP/P/Lは週何日ですか？

週3〜6日の範囲で行えます。最低は3日（プッシュ、プル、レッグを1回ずつ）です。最も効果が出るのは週6日で、各筋群が週2回鍛えられ、休みが1日あります。

### ダンベルP/P/Lのプログレッションはどう進みますか？

ダブルプログレッションです。各種目を、1セット8回以上できる重量から始め、12回×3セットまで伸ばします。3セットすべてで12回に届いたら、コンパウンドもアイソレーション種目も2.5kgずつ（kg 表記では 2.5kg にそろえています）、重量を増やします。

### ゴブレットスクワットが重くなりすぎたらどうすればよいですか？

ゴブレットスクワットは、手持ちの最も重いダンベルが上限になるので、たいてい最初に停滞します。そうなったら、ブルガリアンスクワットかピストルスクワットに替えます。片脚ずつ鍛えるので、軽い重量のままプログレッションを続けられます。

### 懸垂がまだできない場合はどうすればよいですか？

ネガティブ懸垂から始めます。ジャンプして上の位置に上がり、3〜5秒かけてゆっくり下ろします。または、目標のレップをもっと多くのセットに分けます。たとえば、4回×3セットのかわりに2回×6セットにします。丈夫なテーブルの縁を使ったインバーテッドロウで代用してもかまいません。

### ダンベルP/P/Lは自宅トレーニングに向いていますか？

向いています。構造化された自宅ジム向けプログラムの中でも、とくによいものの1つです。必要なのは、重量を変えられるダンベル（または、重さの違う固定のダンベル）、ベンチ（できればインクラインにできるもの）、懸垂バーだけです。バーベル、ケーブル、マシンは要りません。

```liftoscript
# Week 1
## Push Day
main / used: none / 3x12 / progress: custom(increment: 5lb, lastReps: 0, failures: 0) {~
  if (completedReps >= reps) {
    weights += state.increment
    state.failures = 0
    state.lastReps = 0
  } else {
    if (sum(completedReps) <= state.lastReps) {
      state.failures += 1
    } else {
      state.lastReps = sum(completedReps)
    }
    if (state.failures >= 3) {
      weights -= state.increment * 2
      state.lastReps = 0
      state.failures = 0
    }
  }
~}

Bench Press, Dumbbell / ...main / 30lb
Incline Chest Fly / ...main / 20lb / progress: custom(increment: 2.5lb) { ...main }
Arnold Press / ...main / 20lb
Triceps Extension / ...main / 20lb / progress: custom(increment: 2.5lb) { ...main }
Hanging Leg Raise / ...main / 0lb / warmup: none / progress: custom(increment: 2.5lb) { ...main }

## Pull Day
Pull Up / ...main / 0lb / warmup: none
Bent Over Row, Dumbbell / ...main / 30lb
Reverse Fly / ...main / 10lb / progress: custom(increment: 2.5lb) { ...main }
Shrug / ...main / 35lb
Bicep Curl / ...main / 20lb / progress: custom(increment: 2.5lb) { ...main }

## Legs Day
Goblet Squat / ...main / 35lb
Lunge, Dumbbell / ...main / 20lb
Single Leg Deadlift / ...main / 25lb
Standing Calf Raise / ...main / 30lb
Hanging Leg Raise / ...main / 0lb / warmup: none
```
