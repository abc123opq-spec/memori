GZCL: General Gainzは、**GZCLの原則** に基づくウェイトトレーニングのプログラムです。作者は[Cody Lefever](https://www.gainzfever.com/)で、GZCLという名前は彼のRedditユーザー名[u/gzcl](https://www.reddit.com/u/gzcl)に由来します。[VDIP](/programs/gzcl-vdip)や[GZCLP](/programs/gzclp)から[Jacked & Tan 2.0](/programs/gzcl-jacked-and-tan-2)まで、ほかのGZCLプログラムすべての知見をまとめた、Codyの最新作です。

## GZCLの原則

まず、基本的な用語を押さえておきます。

- **レップマックス（RM）**：決まったレップ数でできる最大の重量です。たとえば100kgで5回しかできないなら、5RMは100kgです。測るときは完全な限界まで追い込まず、フォームを保てなくなる手前で止めてください。

次に、種目の分け方です。GZCLのプログラムでは、種目を **3つのティア** に分けます。

- **T1**：メインのコンパウンド種目です（例：[{Squat}]、[{Deadlift}]、[{Bench Press}]、[{Overhead Press}]）。強度は最も高く（2〜3RMの **85〜100%** ほどの重い重量）、ボリュームは少なめです（レップ数もセット数も少なめ）。合計で10〜15回が目安で、多くは1セットあたり **1〜3回** です。
- **T2**：サブのコンパウンド種目です（例：[{Front Squat}]、[{Romanian Deadlift}]、[{Incline Bench Press}]など）。T1より強度は低く（軽い重量）、ボリュームは多くなります（レップ数もセット数も多め）。T1を補助する種目を選んでください。2〜3RMの **65〜85%** で、多くは1セットあたり **5〜8回** です。
- **T3**：アイソレーション種目です（例：[{Leg Press}]、[{Seated Leg Curl}]、[{Triceps Extension}]、[{Lateral Raise}]）。強度は最も低く（最も軽い重量）、ボリュームは最も多くなります（レップ数もセット数も多め）。2〜3RMの **65%** 未満で、多くは1セットあたり **8回以上** です。

覚えやすい目安として、**1:2:3のルール** があります。T1で1回行うごとに、T2で2回、T3で3回行います。

ここで書いたのはGZCLの原則の短い説明です。詳しくは、[Codyのブログ記事](http://swoleateveryheight.blogspot.com/2012/11/the-gzcl-method-for-powerlifting.html)をぜひ読んでください。

## General GainzへのGZCLの原則の当てはめ方

### T1種目

プログレッションは、4つのアクションで進めます。

- **Find（探る）**：3〜6回できる重量（3RM〜6RM）を選んで挑戦し、きつさを評価します。楽（RPE 8、あと2回できる）、中くらい（RPE 9、あと1回できる）、きつい（RPE 10、もう1回もできない）のどれかです。
- **Hold（維持）**：次回は **同じ重量で同じレップ数** に挑戦します（もう一度チャンスを与えるときなど）。
- **Push（伸ばす）**：次回は **同じ重量でレップ数を増やし**、限界に挑戦します。
- **Extend（上乗せ）**：最初の3〜6RMのセットのあとに、**1回のセット（シングル）** を行います。セット数は、最初のRMセットのレップ数に合わせます。たとえば5RMだったなら、同じ重量でシングルを5セット追加します。最初のセットが楽または中くらいだった場合は、追加のセットを最大3セット増やせます。

最初のワークアウトでは **Find** と **Extend** を行います。次回以降は **Hold** か **Push** のどちらかを選び、そのあとにまた **Extend** を行います。

6RMのあとにシングルを6セット行えるようになったら、重量を上げます。

休憩時間は大切です。守らないと、Extendのセットをいつまでも続けられてしまいます。最初のセットのあとは **3〜5** 分、Extendのセットのあとは **2〜3** 分休んでください。

### T2種目

T1とほぼ同じで、4つのアクションの意味も同じです。

- **Find**：6〜10回できる重量（6RM〜10RM）を選んで挑戦し、きつさを評価します。楽（RPE 8、あと2回できる）、中くらい（RPE 9、あと1回できる）、きつい（RPE 10、もう1回もできない）のどれかです。
- **Hold**：次回は **同じ重量で同じレップ数** に挑戦します（もう一度チャンスを与えるときなど）。
- **Push**：次回は **同じ重量でレップ数を増やし**、限界に挑戦します。
- **Extend**：最初の6〜10RMのセットのあとに、**ハーフセット** を行います。最初のセットの半分のレップ数でセットを重ね、合計で最初のセットの2倍のレップ数を目指します。たとえば最初のセットが10RMなら、合計 **20回** を目標に、**5回×4セット**（5 = 10 ÷ 2）を行います。最初のセットが楽または中くらいだった場合は、追加のセットを最大 **2セット** 増やせます。

10RMのあとにExtendのセットをすべてこなせたら、重量を上げます。

ここでも休憩時間は大切です。最初のセットのあとは **2〜4** 分、Extendのセットのあとは **1〜2** 分休んでください。

### T3種目

T3種目は、AMRAP（限界までのレップ数。マックスレップセット、MRSとも呼びます）を3セット行うだけです。セット間の休憩は短く、**30〜90秒** にします。

これも簡単な説明です。詳しい内容は、[GZCL General Gainzを紹介したRedditの元記事](https://www.reddit.com/r/gzcl/comments/aqkdgo/happy_gday_gainerz/)を読んでください。

下のインタラクティブなプレイグラウンドで、プログラムの動きと、各日の重量・セット数・レップ数を確かめられます。RMを行ったあとにシングルやハーフセットを行う、といった流れも試せます。

GZCL: General Gainzは、Memoriアプリで実行できます。

### GZCL General Gainzは中級者に向いていますか？

はい。General Gainzは、中級者から上級者向けに作られています。[GZCLP](/programs/gzclp)、[VDIP](/programs/gzcl-vdip)、[Jacked & Tan 2.0](/programs/gzcl-jacked-and-tan-2)といった過去のGZCLプログラムの要素を、ひとつの柔軟な仕組みにまとめたものです。トレーニング歴が1年以上あり、RMを見積もれることが目安です。

### General Gainzは週何日ですか？

通常は週4日のプログラムとして行いますが、週3〜6日にも対応できる柔軟な枠組みです。各日は、重いT1のコンパウンド種目、中程度のT2のコンパウンド種目、T3のアイソレーション種目で構成されます。

### General Gainzのプログレッションはどう進みますか？

4つのアクションで進めます。Find（RMを測る）、Hold（同じ重量・レップ数をもう一度行う）、Push（同じ重量でレップ数を増やす）、Extend（メインのセットのあとにシングルやハーフセットを行う）です。T1は6RMのあとにシングルを6セット、T2は10RMのあとにExtendのセットをすべてこなせたら、重量を上げます。

### General GainzとGZCLPは何が違いますか？

[GZCLP](/programs/gzclp)は、セット数とレップ数が固定で、リニアプログレッションにより毎回重量が上がります。General Gainzはオートレギュレーションで、重さの感じ方に応じて、Push、Hold、Extendのどれにするかを自分で決めます。柔軟な反面、使いこなすにはトレーニング経験が必要です。

### General Gainzの種目は変えられますか？

はい。このプログラムは固定のルーティンではなく、枠組みです。目標に合わせてT1、T2、T3の種目を選んでください。T1は主要な競技種目、T2はT1を補助するバリエーション、T3は弱点を補うアイソレーション種目にします。

### General Gainzはどのくらいの期間続けますか？

オートレギュレーションなので、無期限に続けられます。決まったサイクルの長さはなく、状況に応じてFind、Push、Hold、Extendを繰り返すだけです。6か月以上続けるリフターも多くいます。

```liftoscript
# Week 1
## Day 1
// **T1**.
// * **Find**: Initially set your 1RM for the exercise, and work up to the first set.
// * **Extend**: Do the same amount of singles (1 rep) as it was your RM, with the same weight. E.g. if you did 4RM, do 4 sets x 1 rep after. You can extend the number of sets up to 3 extra sets (e.g. for 4RM - up to 7 sets x 1 rep max) if 4RM was easy.
// * Next time, you'd either try to do the same number of reps with the same weight (**Hold**), or try to **Push** and do more reps.
// * If you are able to do 6 reps with 6 extensions, the weight will be increased next time
t1 / used: none / 1+x3-6 85% / 180s / update: custom() {~
  if (setIndex == 1) {
    numberOfSets = completedReps[1] > 2 ? completedReps[1] + 1 : 2
    sets(2, 99, 1, 1, 0, completedWeights[1], 180, 0, 0)
  }
~} / progress: custom() {~
  if (completedReps >= reps && numberOfSets == 7) {
    weights += 5lb
  }
~}

// **T2**.
// * **Find**: Initially set your 1RM for the exercise, and work up to the first set.
// * **Extend**: Do the of "halfes" sets (your RM from the first set / 2) so the volume would be double of your RM. E.g. if you did 10RM, do 4 sets x 5 reps (20 total) after. You can extend the number of sets up to 2 extra sets if 10RM was easy.
// * Next time, you'd either try to do the same number of reps with the same weight (**Hold**), or try to **Push** and do more reps.
// * If you are able to do 10RM with 4 extensions, the weight will be increased next time
t2 / used: none / 1+x6-10 75%, 4x1 75% / 120s / update: custom() {~
  if (setIndex == 1) {
    sets(2, 99, floor(completedReps[1] / 2), floor(completedReps[1] / 2), 0, completedWeights[1], 120, 0, 0)
  }
~} / progress: custom() {~
  if (completedReps >= reps) {
    weights += 5lb
  }
~}

// **T3**. All sets are Max Rep Sets (AMRAP).
t3 / used: none / 3x10+ 50% / 90s

// ...t1
t1: Squat / ...t1
// ...t2
t2: Romanian Deadlift, Barbell / ...t2
// ...t3
t3: Seated Leg Curl / ...t3
// ...t3
t3: Leg Extension / ...t3
```
