VDIPはVolume-dependent Intensity Progression（ボリューム依存の強度プログレッション）の略です。少し変わったプログラムで、すべての種目のすべてのセットをAMRAP（限界までのレップ数）で行い、全セットの合計レップ数をもとに重量を上げます。

始める前に、必ず[作者のブログにあるプログラムの解説](https://swoleateveryheight.blogspot.com/2016/11/volume-dependent-intensity-progression.html)を読んでください。

GZCL: VDIP（Volume-dependent Intensity Progression）は、**GZCLの原則**にもとづくウェイトトレーニングのプログラムです。作者は[Cody Lefever](https://www.gainzfever.com/)で、GZCLという名前は彼のRedditのユーザー名[u/gzcl](https://www.reddit.com/u/gzcl)に由来します。初級から中級者向けで、すべてのセットをAMRAPで行うのが中心の考え方です。

## GZCLの原則

まず、基本の用語を押さえておきます。

- **レップマックス（RM）**：決まったレップ数でできる最大の重量です。たとえば100kgで5回しかできないなら、5RMは100kgです。測るときは完全な限界までやらず、フォームを保てなくなる手前で止めてください。

次に、種目の分け方です。GZCLのプログラムでは、種目を**3つのティア**に分けます。

- **T1**：メインのコンパウンド種目です（例：[{Squat}]、[{Deadlift}]、[{Bench Press}]、[{Overhead Press}]）。強度は最も高く（2〜3RMの**85〜100%**ほどの重い重量）、ボリュームは少なめです（レップ数もセット数も少なめ）。合計で10〜15回が目安で、多くは1セットあたり**1〜3回**です。
- **T2**：サブのコンパウンド種目です（例：[{Front Squat}]、[{Romanian Deadlift}]、[{Incline Bench Press}]など）。T1より強度は低く（軽い重量）、ボリュームは多くなります（レップもセットも多め）。T1を補助する種目を選んでください。2〜3RMの**65〜85%**で、1セットあたり**5〜8回**が目安です。
- **T3**：アイソレーション種目です（例：[{Leg Press}]、[{Seated Leg Curl}]、[{Triceps Extension}]、[{Lateral Raise}]）。強度は最も低く（軽い重量）、ボリュームは最も多くなります（レップもセットも多め）。2〜3RMの**65%未満**で、1セットあたり**8回以上**が目安です。

覚えやすい目安として、**1:2:3のルール**があります。T1で1回行うごとに、T2で2回、T3で3回行います。

ここで書いたのはGZCLの原則の短い説明です。詳しくは、[Codyのブログ記事](http://swoleateveryheight.blogspot.com/2012/11/the-gzcl-method-for-powerlifting.html)をぜひ読んでください。

## VDIPプログラムへのGZCLの原則の当てはめ方

### T1種目

最初に、開始重量を決めます。その種目の2RMの**約85%**です。

**3セット**行います。このプログラムでは、すべての種目のすべてのセットが、マックスレップセット（AMRAP）です。完全な限界までは追い込まず、あと1〜2回できる余力を残して、できるだけ多く行います。後のセットほどレップ数は減っていきますが、それで問題ありません。重量は自動で調整されます。全セットのレップ数の合計が**15回**以上なら**5kg**、**10回**以上なら**2.5kg**増えます。

ここでは休憩タイマーが大切です。T1の休憩は**3〜5分**にしてください。

### T2種目

T1と似ていますが、開始重量はその種目の2RMの**約65%**です（1セットあたり、より多くのレップができるはずです）。

合計**30回**以上なら**5kg**、合計**25回**以上なら**2.5kg**増えます。

休憩タイマーはT1より短く、T2では**2〜3分**です。

### T3種目

T1・T2と同じですが、セット数は**4セット**です。開始重量は、その種目の2RMの**約55%**です。

合計**50回**以上なら**2.5kg**増えます。

休憩タイマーはさらに短く、T3では**30〜90秒**です。

ここまでは簡単な説明です。詳しい内容は、[GZCL VDIPの元記事](http://swoleateveryheight.blogspot.com/2016/11/volume-dependent-intensity-progression.html)を読んでください。

下のインタラクティブなプレイグラウンドで、プログラムの仕組みと、各日の重量・セット数・レップ数を確認できます。セットを完了させると、次のワークアウトで重量がどう変わるかも見られます。

GZCL: VDIPのプログラムは、Memoriアプリで実行できます。

### GZCL VDIPは、ほかのGZCLプログラムと何が違いますか？

VDIPの特徴は、すべてのセットがAMRAP（できるだけ多くのレップ）であることです。重量は、全セットの合計レップ数をもとに上がるので、プログレッションはすべてボリュームしだいです。調子のよい日は早く進み、悪い日は同じ重量を維持するという、自然な調整になります。

### GZCL VDIPは初心者に向いていますか？

VDIPは、初心者から中級者に向いています。AMRAPが中心の方式は、決まった目標レップ数がないぶん、無理なく取り組めます。ただし、決められたレップ数がなく「できるだけ多く」行うだけなので、すべてのセットで自分を追い込む自制心が必要です。

### GZCL VDIPは週に何日ですか？

VDIPは週5日のプログラムです。毎日、GZCLのティアに従ってT1、T2、T3の種目があります。頻度が高いので、各筋群を週に複数回鍛えます。

### GZCL VDIPのプログレッションはどう進みますか？

全セットの合計レップ数が基準に達すると、重量が上がります。T1（3セット）は、合計15回以上で5kg、10回以上で2.5kgです。T2（3セット）は、30回以上で5kg、25回以上で2.5kgです。T3（4セット）は、合計50回以上で2.5kgです。

### GZCL VDIPでは、休憩時間をどうすればよいですか？

休憩は、T1のセット間が3〜5分、T2のセット間が2〜3分、T3のセット間が30〜90秒です。この休憩時間を守ってください。長く休むと多くのレップができてしまい、プログレッションの基準を満たしやすくなります。

### GZCL VDIPは、どのくらいの期間続ければよいですか？

伸び続けるかぎり続けてください。多くのリフターは、3〜6か月で伸びが大きく鈍ります。そのあとは、[The Rippler](/programs/gzcl-the-rippler)や[Jacked & Tan 2.0](/programs/gzcl-jacked-and-tan-2)のような、ピリオダイゼーションを取り入れたGZCLプログラムに移ってください。

```liftoscript
# Week 1
## Day 1
t1 / used: none / 3x1+ 80% / 180s / progress: custom() {~
  if (sum(completedReps) >= 15) {
    weights += 10lb
  } else if (sum(completedReps) >= 10) {
    weights += 5lb
  }
~}
t2 / used: none / 3x1+ 60% / 120s / progress: custom() {~
  if (sum(completedReps) >= 30) {
    weights += 10lb
  } else if (sum(completedReps) >= 25) {
    weights += 5lb
  }
~}
t3 / used: none / 4x1+ 50% / 60s / progress: sum(50, 5lb)

t1: Squat / ...t1
t2: Stiff Leg Deadlift / ...t2
t3: Lunge / ...t3
t3: Pull Up / ...t3

## Day 2
t1: Bench Press / ...t1
t2: Bent Over Row / ...t2
t3: Bench Press Close Grip / ...t3
t3: Shoulder Press / ...t3

## Day 3
t1: Deadlift / ...t1
t2: Front Squat / ...t2
t3: Bent Over One Arm Row / ...t3
t3: Seated Row / ...t3

## Day 4
t1: Overhead Press / ...t1
t2: Push Press, Barbell / ...t2
t3: Incline Bench Press / ...t3
t3: Chest Dip / ...t3

## Day 5
t1: Front Squat / ...t1
t2: Squat / ...t2
t3: Lat Pulldown / ...t3
t3: Bicep Curl, EZ Bar / ...t3
```
