6種目を毎回繰り返すだけの、とてもシンプルな筋肥大プログラムです。最後のセットで13回以上できたら重量を上げます。

開始重量を決めて、`weight` 変数に設定してください。軽めから始めるのがおすすめです。自動プログレッションがすぐに適正な重量へ調整してくれます。

<!-- more -->

アーノルド・シュワルツェネッガーのゴールデンシックスは、伝説的なボディビルダーであり俳優でもある彼が、キャリア初期に広めた定番の全身筋肥大ワークアウトです。このプログラムは初心者向けとしてよく勧められます。内容はとてもシンプルで、コンパウンド種目が中心、初心者に十分なボリュームと頻度も確保できます。1回のワークアウトも1時間ほどで終わります。

中級者・上級者は、ボリュームも種目の選択肢も多い[5/3/1 Boring But Big](/programs/the531bbb)やDr. Swoleの上下分割プログラムなど、ほかの筋肥大プログラムのほうが向いています。

進め方はシンプルです。1日6種目を、1日おきの週3日で繰り返します。

1. [{Squat}]：10回×4セット。スクワットは下半身と体幹の筋力をつける基本の種目です。
2. [{Bench Press Wide Grip}]：10回×3セット。胸・肩・上腕三頭筋に効き、特に胸への刺激が強い種目です。ワイドグリップは大胸筋を鍛えるのに向いています。
3. [{Chin Up}]：AMRAP（限界までのレップ数）。1回もできない場合は、アシスト付きのチンアップマシンを使うか、ネガティブチンアップから始めてください。主に背中と上腕二頭筋に効きます。
4. [{Behind The Neck Press}]：10回×4セット。肩と上腕三頭筋に効く種目です。ビハインドネックの部分は、フォームが悪いと肩に負担がかかるので注意してください。違和感がある場合は、体の前で押す通常のオーバーヘッドプレスが代わりになります。
5. [{Bicep Curl}]：10回×3セット。主に上腕二頭筋に効く種目です。カールの間はひじを動かさず、狙った筋肉にしっかり効かせてください。違和感がある場合は、ダンベルカールが代わりになります。
6. [{Crunch}]：AMRAP（限界までのレップ数）。体幹を鍛えるのによい種目です。

プログレッションは、最後のセットをAMRAP（限界までのレップ数）で行って判断します。[{Chin Up}]と[{Crunch}]は、次回は今回できた回数より最低1回多くやります。そのほかの種目は、13回以上できていたら、次のワークアウトで重量を2.5kg上げます。

### アーノルドのゴールデンシックスは初心者に向いていますか？

はい。ゴールデンシックスは、数ある初心者向け筋肥大プログラムのなかでも特にシンプルな部類です。種目は6つだけで、毎回同じものを週3日行います。構成がわかりやすいので、プログラムの組み方に悩まず、動作を覚えてトレーニングの習慣をつけることに集中できます。

### アーノルドのゴールデンシックスは週何日ですか？

1日おきに行う週3日のプログラムです。月・水・金などが目安です。毎回同じ6種目なので、覚える内容も交互に切り替える内容もありません。

### アーノルドのゴールデンシックスのプログレッションはどうなっていますか？

各種目の最後のセットがAMRAP（限界までのレップ数）です。バーベル種目は、そのAMRAPセットで13回以上できたら、次のワークアウトで重量を2.5kg上げます。チンアップとクランチは、毎回前回より最低1回多くできることを目指します。

### アーノルドのゴールデンシックスはどのくらい続けるのがよいですか？

3〜6か月、または安定して伸びなくなり、種目の種類やボリュームを増やしたくなるまでが目安です。その後は、[PHUL](/programs/phul)や[5/3/1 Boring But Big](/programs/the531bbb)のような、スプリット形式の中級者向けの筋肥大プログラムに移ってください。

### アーノルドのゴールデンシックスの種目は入れ替えられますか？

はい。ビハインドネックプレスで肩に違和感がある場合は、通常のオーバーヘッドプレスに替えられます。ワイドグリップベンチプレスは通常のベンチプレスに替えて構いません。チンアップができない場合は、アシスト付きのチンアップマシンか、ラットプルダウンを使ってください。

### アーノルドのゴールデンシックスだけで筋肉はつきますか？

初心者なら十分につきます。コンパウンド種目で主要な筋群すべてに、必要なボリュームと頻度を確保できます。中級者・上級者には、ボリュームも種目の種類も、プログレッシブオーバーロードの工夫も足りなくなるでしょう。

```liftoscript
# Week 1
## Day 1
Squat / 3x10, 1x10+ / progress: custom() {~
  if (
    completedReps >= reps &&
    completedReps[numberOfSets] >= reps[numberOfSets] + 3
  ) {
    weights += 5lb
  }
~}
Bench Press Wide Grip / 2x10, 1x10+ / progress: custom() { ...Squat }
Chin Up / 3x1+ / 0lb / warmup: none / progress: custom(weight: 0lb, reps: 1) {~
  if (completedReps >= reps) {
    reps = completedReps[ns] + 1
  }
~}
Overhead Press / 4x10 / warmup: 1x5 50%
Bicep Curl / 3x10 / warmup: none
Crunch / 3x1+ / 60s / warmup: none
```
