Bill Starrの5x5方式を土台にした中級者向けの筋力プログラムで、Starting StrengthやStrongLiftsのような初心者向けのプログラムを卒業したリフター向けに作られています。毎回重量を増やす代わりに、全身を鍛える3日間でヘビー・ライト・ミディアムの枠組みを使い、週単位のリニアプログレッションで進めます。毎回のワークアウトでは、段階的に重くするセットを積み上げて、トップセットを1回行います。

## 由来と考え方

Madcow 5x5は、「Madcow」（「Madcow2」とも）というフォーラム投稿者が広めました。2000年代半ばに[EliteFitness.com](https://www.elitefitness.com/forum/threads/bill-starrs-5-x-5-program-variation-per-madcow2-thanx-so-here-it-is-k-up-now.375215/)やbodybuilding.comで活動していた人物です。Bill Starrが1976年の著書 *The Strongest Shall Survive* で紹介したヘビー・ライト・ミディアムの5x5方式を改良したものです。Madcowは[Glenn Pendlayと話したと伝えられており](https://stronglifts.com/stronglifts-5x5/history/)（PendlayはPendlay Rowの由来となったオリンピックリフティングのコーチで、Texas Methodの共同考案者でもあります）、元のプログラムを取り組みやすくしました。パワークリーンなどのオリンピックリフトを[{Bent Over Row}]に、ハイプルを[{Deadlift}]に置き換えています。

中心にある考え方は次のとおりです。毎回重量を増やせなくなったら（初心者の特徴です）、もっと長い回復のサイクルが必要になります。Madcowは、ストレス・回復・適応のサイクルを1週間全体に広げています。月曜に重い刺激を与え、水曜は積極的な回復にあて、金曜は次の月曜に5回のフルセットに挑む前に、さらに重い重量で3回を試します。この「予告して、証明する」やり方が、筋力と自信の両方を育てます。

## 向いている人

- **経験レベル**：初心者の後半から中級者の前半（バーベルトレーニングを6〜18か月継続していること）。Starting Strength、StrongLifts 5x5、[GZCLP](/programs/gzclp)のような初心者向けのリニアプログレッションを終え、毎回重量を増やすことができなくなっていること。
- **前提条件**：[{Squat}]、[{Bench Press}]、[{Deadlift}]、[{Incline Bench Press}]、[{Bent Over Row}]のフォームに慣れていること。メイン種目の5RMがわかっていること。
- **主な目的**：筋力アップ。金曜のバックオフセットで多少の筋肥大も得られます。
- **おすすめの時期**：増量期か維持期です。毎週PRを狙うには十分な回復が必要なので、カロリーが不足していると、伸ばし続けられる期間が短くなります。

## メリットとデメリット

**メリット**

- [{Squat}]を週3回、強度を変えて行うので、フォームと動作の質が速く身につきます
- 段階的に重くするセット（トップセットの前に4セット、少しずつ重くするウォームアップ）が、あらかじめ組まれた構造的なウォームアップになります
- 金曜に重い重量で行う3回が、翌週月曜の目標を「予告」するので、PRに挑む自信がつきます
- 月・水・金の3日というシンプルな構成で、複雑な割合のサイクルがありません
- 週単位のプログレッションなので、毎回重量を増やすプログラムよりずっと長い、8〜12週間は続けられます

**デメリット**

- [{Bench Press}]と[{Bent Over Row}]は週2回（月曜と金曜）しかなく、[{Incline Bench Press}]と[{Deadlift}]は週1回（水曜）だけです
- AMRAPセットがないので、その日の調子に合わせた自動調整はできません
- 上背部と肩の補助種目のボリュームが少ないです。肩や三角筋後部が弱いリフターは、自分で種目を足してください
- 停滞したときの選択肢は、ディロードをして最初からやり直すことくらいです。GZCLPのようなステージの仕組みは組み込まれていません

## プログラムの構成

- **分割**：全身、週3日
- **ピリオダイゼーション**：ヘビー・ライト・ミディアムの週単位の変動
- **スケジュール**：月曜・水曜・金曜に固定
- **月曜（Workout A、ヘビー）**：最もボリュームが多い日です。[{Squat}]、[{Bench Press}]、[{Bent Over Row}]は、それぞれ5セットで5回ずつ重量を上げていき、現在の作業重量でトップセットを行います。
- **水曜（Workout B、ライト）**：回復の日です。[{Squat}]は、月曜のトップセットの約75%で終わります。[{Incline Bench Press}]と[{Deadlift}]は、ほかの日に出てこないので、それぞれの段階的に重くするセットを行います。
- **金曜（Workout C、ヘビー）**：PRの日です。[{Squat}]、[{Bench Press}]、[{Bent Over Row}]は、月曜のトップセットより少し重い重量で3回まで重量を上げ、そのあと筋肥大のための8回のバックオフセットを1回行います。

## 種目の選び方と理由

[{Squat}]、[{Bench Press}]、[{Bent Over Row}]が中心で、月曜と金曜の両方に入っています。これで、スクワットと上半身の2つのコンパウンド種目が、週2回、違う強度で重い刺激を受けます。[{Bent Over Row}]は、水平方向のプレスに対して、水平方向の引く動作で釣り合いを取ります。

水曜は[{Bench Press}]を[{Incline Bench Press}]に替え、違う角度のプレスを入れつつ、フラットベンチを休ませます。[{Deadlift}]を水曜だけにしているのは、週3回のスクワットで体の後ろ側がすでに大きく消耗しているからで、重いデッドリフトを増やすと回復が追いつかなくなります。

補助種目は1日につき1種目だけです。月曜は[{Bicep Curl}]、水曜は[{Skullcrusher}]、金曜は[{Hammer Curl}]です。メイン種目の回復を妨げずに、複数の日にわたって腕を直接鍛えます。元のMadcowプログラムには、ほかにも補助種目（ハイパーエクステンション、シットアップ、ディップス）の指定があり、アレンジとして足せます。

**入れ替えの候補**：水曜の[{Incline Bench Press}]は[{Overhead Press}]に替えられます。[{Bent Over Row}]は[{Pendlay Row}]に替えられます。[{Bicep Curl}]と[{Hammer Curl}]は、互いに、または[{Chin Up}]に替えられます。

## セットとレップの組み方

- **月曜のメイン種目**：5セットで5回ずつ、1RMの約40%から約85%まで重量を上げます。きついのは最後のトップセットだけで、その前の4セットは、1RMの40%、55%、65%、75%の段階的なウォームアップです。
- **水曜のメイン種目**：5回を4セット、1RMの約65%（月曜のトップセットの約75%）まで上げます。大きな疲労を生まずに回復を促せる軽さです。
- **金曜のメイン種目**：5回を4セットで段階的に上げ（40%、55%、65%、75%）、そのあと月曜のトップセットより少し重い重量で3回を1セット行います（セット4を終えると、アプリが自動で3回の重量を週ごとの増量分だけ上げます）。最後に、筋肥大のため約65%で8回のバックオフセットを1回行います。
- **補助種目**：8〜12回を3セット、ダブルプログレッションで進めます。回復を妨げずに、メイン種目を支えます。

## プログレッシブオーバーロード

このプログラムは**週単位のリニアプログレッション**を使います。金曜のワークアウトが成功すると、重量が上がります。

- **[{Squat}]**：すべてのセットで週に+2.5kg
- **[{Bench Press}]と[{Bent Over Row}]**：すべてのセットで週に+2.5kg（kg 表記では 2.5kg にそろえています）
- **[{Incline Bench Press}]**：週に+2.5kg（独立して進みます。kg 表記では 2.5kg にそろえています）
- **[{Deadlift}]**：週に+2.5kg（独立して進みます）

**仕組み**：金曜に、月曜のトップセットより約2.5kg（上半身も2.5kg。kg 表記では 2.5kg にそろえています）重い重量で3回に挑みます。金曜に決められたレップをすべてこなせたら、アプリが翌週のすべてのセットに増量分を加えます。次の月曜は、その金曜の3回の重量で、5回のフルセットに挑みます。

**失敗したとき**：翌週にもう一度、同じ重量に挑んでください。1回調子が悪かっただけでは、停滞したとは言えません。睡眠、栄養、ストレスのすべてが成績に影響します。

**同じ重量で2回失敗したとき**：その種目の1RMをアプリで約10%下げます。すべての作業重量が比例して下がります。3〜4週間かけて元に戻してください。ディロードするのは停滞した種目だけで、プログラム全体ではありません。

**ディロードの前に**試すこと：週の増量を2.5kgから1.25kgに変える（とくにプレス系）、重いセットの前の休憩を5分に延ばす、重いスクワットとデッドリフトでベルトを使う、などです。

## 続ける期間と次のプログラム

Madcowは、**合計12〜16週間**行ってください。最初の2〜3週間は、作業重量を見つけるあいだなので、中程度に感じるはずです。停滞するまでに、8〜12週間は本物のPRが出ると考えてください。

**次に進む目安**：同じ種目でディロードして立て直すのが2回目になった、金曜の3回を粘って挙げている、睡眠も栄養も良いのに3週間以上同じ重量で止まっている、といったときです。

**次の候補**：[5/3/1 for Beginners](/programs/the5314b)（月ごとに進み、AMRAPセットがあります）、[The Rippler](/programs/gzcl-the-rippler)のような **GZCLのプログラム**（ティア制で、ボリュームが多めです）、[Texas Method](/programs/texasmethod)（週の構成は似ていて、月曜のボリュームがより多めです）。筋肥大を重視するなら、[PHUL](/programs/phul)か[Lyle's Generic Bulking](/programs/lylegenericbulking)も候補です。

## 必要な器具

バーベル、スクワットラック、フラットベンチ、角度を変えられるインクラインベンチ、プレート（上半身の種目でマイクロローディングをするための0.5kgのプレートを含む）。カールとスカルクラッシャー用のダンベル。

**自宅ジムでの代用**：
- [{Incline Bench Press}] → 角度を変えられるベンチがなければ[{Overhead Press}]
- [{Skullcrusher}] → [{Triceps Extension}]か[{Triceps Dip}]
- [{Hammer Curl}] → [{Bicep Curl, Barbell}]か[{Chin Up}]

## 休憩時間

- **段階的に重くするセット／ウォームアップ**（メイン種目のセット1〜3）：**90〜120秒**。準最大の重さなので、テンポよく進めます。
- **重いセット**（月曜のセット4〜5、金曜のセット4）：**3〜5分**。最大限の力を出すには、ホスホクレアチンの完全な回復が必要です。
- **金曜の3回**：挑む前に**5分**。この週でいちばん重い重量です。
- **水曜（ライトの日）**：すべてのセットの間に**2〜3分**。重く感じるセットはないはずです。
- **補助種目**：**60〜90秒**。

## 開始重量の決め方

メイン種目ごとに、**アプリで1RMを設定してください**。1RMがわからないときは、次の式を使います。**1RM = 5RM / 0.85**。たとえば、スクワットで112.5kgを5回できるなら、推定1RMは132.5kgです。

1RMを設定すると、月曜のトップセットは1RMの85%（ほぼ5RM）から始まります。最初に慣らし期間を組み込みたいなら（おすすめです）、実際の1RMより**5〜10%高い**1RMを入力してください。最初の2〜3週間は余裕のある重さになり、本当のPRは3〜4週目あたりから始まります。

**よくある間違い**：重すぎる重量から始めることです。月曜のトップセットが1週目から粘る重さだと、すぐに停滞します。最初の週は、きつくても8/10の努力度に感じる程度にしてください。軽く始めて、週ごとのプログレッションで新しい領域へ進みます。

## よくあるアレンジ

- 水曜の **[{Incline Bench Press}]を[{Overhead Press}]に替える**と、肩がより発達します
- どの日でも **[{Face Pull}]を足す**（15〜20回×3セット）と、三角筋後部と回旋筋腱板のケアになります
- **[{Bent Over Row}]を[{Pendlay Row}]に替える**と、より厳密で爆発的なロウのバリエーションになります
- 水曜に **[{Hanging Leg Raise}]**（10回×3セット）か[{Sit Up}]を足すと、腹筋を直接鍛えられます
- 月曜か金曜に **[{Back Extension}]**（10回×2セット）か[{Chest Dip}]（8回×3セット）を足すと、体の後ろ側か胸のボリュームを増やせます
- 週2.5kg（kg 表記では 2.5kg にそろえています）の増量ですぐ停滞するなら、**上半身の増量を1.25kgに減らします**（片側0.625kg相当のマイクロプレートが必要で、プログラムの増量を書き換えます）
- **[{Bicep Curl}]を[{Chin Up}]に替える**と、上腕二頭筋にも効くコンパウンド種目の引く動作になります

<!-- faq -->

### Madcow 5x5は初心者に向いていますか？

向いていません。Madcowは、Starting StrengthやStrongLifts 5x5のような初心者向けのプログラムで、毎回重量を増やすことができなくなったリフター向けの、中級者のプログラムです。始める前に、バーベルトレーニングを少なくとも6〜18か月継続し、5RMを把握している必要があります。

### Madcow 5x5は週何日ですか？

Madcowは週3日のプログラムで、通常は月・水・金に行います。月曜は重い日、水曜は軽い回復の日、金曜はより重い3回に挑むPRの日です。

### Madcow 5x5の進め方はどうなっていますか？

Madcowは、毎回ではなく週単位のリニアプログレッションを使います。金曜に、月曜のトップセットより少し重い重量で3回に挑みます。成功したら、翌週にすべての重量が上がります。スクワットとデッドリフトは週に2.5kg、上半身の種目も週に2.5kg（kg 表記では 2.5kg にそろえています）です。

### Madcow 5x5はどのくらい続けるのですか？

12〜16週間です。2〜3週間の慣らし期間のあと、8〜12週間は本物のPRが出ると考えてください。同じ種目でディロードして立て直すのが2回目になったとき、または3週間以上止まっているときは、次に進みます。

### Madcow 5x5で停滞したらどうすればよいですか？

まず、翌週にもう一度同じ重量に挑んでください。1回調子が悪かっただけでは、停滞とは言えません。同じ重量で2回失敗したら、その種目の1RMを10%下げ、3〜4週間かけて元に戻します。ディロードするのは停滞した種目だけで、プログラム全体ではありません。

### Madcow 5x5の段階的に重くするセット（ランプ）とは何ですか？

5セットを同じ重量で行う代わりに、セットごとに重量を上げていきます（1RMの40%、55%、65%、75%、85%）。きついのは最後のトップセットだけです。その前のセットが、あらかじめ組まれた構造的なウォームアップになります。

```liftoscript
# Week 1
## Workout A
main / used: none / 1x5 40%, 1x5 55%, 1x5 65%, 1x5 75%, 1x5 85% / progress: custom(increment: 5lb) {~
  if (completedReps >= reps && dayInWeek == 3) {
    weights += state.increment
  }
~} / update: custom() {~
  if (dayInWeek == 3 && setIndex == 4) {
    if (completedReps[setIndex] >= reps[setIndex]) {
      weights[5] = weights[5] + state.increment
    }
  }
~}
Squat / ...main[1]
Bench Press / ...main[1] / progress: custom(increment: 2.5lb) { ...main }
Bent Over Row / ...main[1] / progress: custom(increment: 2.5lb) { ...main }
Bicep Curl / 3x8-12 / progress: lp(5lb)

## Workout B
main / 1x5 40%, 1x5 55%, 2x5 65%
Squat / ...main[2]
Incline Bench Press / ...main[2] / progress: lp(2.5lb)
Deadlift / ...main[2] / progress: lp(5lb)
Skullcrusher / 3x8-12 / progress: lp(5lb)

## Workout C
main / 1x5 40%, 1x5 55%, 1x5 65%, 1x5 75%, 1x3 85%, 1x8 65%
Squat / ...main[3]
Bench Press / ...main[3]
Bent Over Row / ...main[3]
Hammer Curl / 3x8-12 / progress: lp(5lb)
```
