毎回のワークアウトに引く種目（チンアップとロウ）を加えた、初心者向けのリニアプログレッションです。全身のワークアウトを2種類交互に、週3日行います。最後のセットはAMRAPで、強度が自動で調整され、攻めの進め方の根拠にもなります。デッドリフトは、重い1セットのAMRAPだけにして、ワークアウトを短く保ちます。

## 由来と考え方

Redditのr/FitnessコミュニティのモデレーターであるPhraktureが、John Sheaffer（通称Johnny Pain）の考案したGreyskull LPをもとに作ったバリエーションです。元のGSLPは、メイン種目が押す種目と下半身の種目だけで、背中のトレーニングが抜けていました。Phraktureは、毎回のワークアウトに[{Chin Up}]と[{Bent Over Row}]を足し、プッシュ・プル・レッグのバランスがとれた構成にしました。

GSLPから受け継いだ考え方の核は、どのワークセットの組み方も、最後がAMRAPセットで終わることです。いずれ停滞して10%ディロードしても、軽い重量で高レップをこなしながら戻っていくので、ディロードが無駄な時間ではなく、筋肥大のフェーズになります。

## 向いている人

- **経験**：完全な初心者（トレーニング歴0〜6か月）、または長い休みのあとに戻ってきた人
- **目的**：フォームを学びながら、バーベルのコンパウンド種目で土台となる筋力をつけること
- **食事**：どんな食事でも続けられます。初心者なら、カロリー不足でも筋力は伸びます。

## メリットとデメリット

**メリット**

- 縦に押す・引く（[{Overhead Press}]と[{Chin Up}]）と、横に押す・引く（[{Bench Press}]と[{Bent Over Row}]）を、日を分けて交互に行うので、上半身がバランスよく育ちます
- 最後のAMRAPセットが強度を自動で調整します。調子の良い日はボリュームが増え、悪い日は自然に抑えられます
- [{Deadlift}]を1セットにすることで、デッドリフトの日を30分以内に収めながら、重い刺激も入れられます
- 攻めの進め方（AMRAPで10回以上なら重量の増やし幅が2倍）で、最初の数週間が楽すぎると感じずに済みます

**デメリット**

- 腕、肩、体幹を直接鍛えるアイソレーション種目がありません。もっと鍛えたいなら、カール、フェイスプル、腹筋を自分で足してください
- [{Deadlift}]のワークセットが1回に1セットだけです。フォームを身につけるにはボリュームが少なすぎると感じる人もいます
- 上半身は、原文では1.25kgずつ増やします。このアプリのkg表記では2.5kgずつにそろえています（1.25kgずつ進めるには、片側0.625kg相当のマイクロプレートが必要です）
- 自重の[{Chin Up}]には、重量を下げる方法がありません。5回できないなら、[{Lat Pulldown}]やネガティブ動作で代用してください

## プログラムの構成

- **分割**：全身、A/Bの交互
- **ピリオダイゼーション**：リニアプログレッション。AMRAPで進み方が早まり、失敗したら10%ディロードします
- **ローテーション**：1週目はA/B/A、2週目はB/A/B、以降は繰り返し

月・水・金で行う場合の、2週間の流れです。

| | 月曜 | 水曜 | 金曜 |
|---|--------|-----------|--------|
| 1週目 | ワークアウトA | ワークアウトB | ワークアウトA |
| 2週目 | ワークアウトB | ワークアウトA | ワークアウトB |

（ワークアウトA・Bは、アプリ上ではそれぞれWorkout A・Workout Bと表示されます。）

## 種目の選び方と理由

**ワークアウトA**は、縦の動きの組み合わせです。[{Overhead Press}]（縦に押す）、[{Chin Up}]（縦に引く）、[{Squat}]（大腿四頭筋優位の下半身）を行います。縦の組み合わせで、1回のワークアウトのうちに、肩と広背筋をバランスよく育てられます。

**ワークアウトB**は、横の動きの組み合わせです。[{Bench Press}]（横に押す）、[{Bent Over Row}]（横に引く）、[{Deadlift}]（股関節優位の下半身）を行います。ロウは、ベンチプレスを安定させる上背部の筋肉を直接鍛えます。

[{Squat}]は3回のうち2回、[{Deadlift}]は3回のうち1回登場します。高重量のデッドリフトは回復の負担が大きいためです。

**代替**：自重のチンアップがまだできないなら、[{Chin Up}]を[{Lat Pulldown}]に替えます。[{Bent Over Row}]は、バーベルロウのどのバリエーションでも構いません。Phrakture本人は、イェーツロウ（上体をやや起こし、逆手で行う）を勧めています。

## セットとレップの設計

全種目、**5回×2セット、5回以上×1セット（AMRAP）**です。2セットを5回ずつ行い、最後の1セットをAMRAPにします。例外は[{Deadlift}]で、**5回以上×1セット**の、AMRAP1セットだけです。

AMRAPセットは、フォームを保ったままできるだけ多くのレップを行うセットです。RPE 8〜9（あと1〜2回できる余力を残す）で止めてください。完全な限界まで粘ってはいけません。AMRAPのレップ数が、重量を普通に上げるのか、早く上げるのか、ディロードするのかを決めます。

## プログレッシブオーバーロード

**成功したワークアウトのあと**（指定のレップをすべて達成）：

| 種目の種類 | 通常の増やし幅 | 攻めの増やし幅（AMRAPで10回以上） |
|-----------|------------------|--------------------------------------|
| 上半身（[{Overhead Press}]、[{Bench Press}]、[{Chin Up}]、[{Bent Over Row}]） | +2.5kg（kg 表記では 2.5kg にそろえています） | +2.5kg |
| 下半身（[{Squat}]、[{Deadlift}]） | +2.5kg | +5kg |

**失敗したとき**（指定のレップを達成できなかった）：重量を**10%**下げて、積み直します。

種目ごとに、それぞれ独立して進みます。[{Bench Press}]で停滞しても、[{Squat}]には影響しません。

ディロードして積み直す流れは、欠点ではなく仕組みの一部です。軽い重量で高レップのAMRAPをこなしながら戻ると、筋肥大の刺激が入り、停滞を抜けるのに必要な筋肉がつきます。

## どのくらい続けるか・次のプログラム

**2〜4か月**続けてください。複数の種目で頻繁にディロードするようになり、AMRAPが5回ぎりぎりになったら、次に進みます。

**次におすすめのプログラム**：
- [GZCLP](/programs/gzclp)：ティア構造で、ボリュームが増える
- [5/3/1 for Beginners](/programs/the5314b)：ピリオダイゼーションがあり、補助種目も組み込まれている

## 必要な器具

- バーベル、プレート、スクワットラック、フラットベンチ
- 懸垂バー、または[{Lat Pulldown}]のマシン
- **マイクロプレート**（片側0.625kg相当）：原文の1.25kgずつの増やし幅に必要です。このアプリでは2.5kgずつにそろえているので、なくても進められますが、ディロードは増えます。

**自宅ジムでの代替**：[{Chin Up}]ができないなら、バンドで補助したチンアップか、代わりに[{Inverted Row}]を使います。

## 休憩時間

- **セット間**：2〜3分
- **種目間**：3〜5分
- 高重量の[{Squat}]と[{Deadlift}]は、5分たっぷり必要なこともあります。[{Chin Up}]と[{Bent Over Row}]は、2分で十分です。

## 開始重量の決め方

初日は、種目ごとに次の手順で決めます。

1. 空のバー（20kg）で5回行う
2. 5〜10kg足して、5回行う
3. フォームが崩れ始めるか、バーのスピードが目に見えて落ちるまで繰り返す
4. その重量を開始重量にする

**思ったより軽く始めてください。** リニアプログレッションは毎回重量が増えるので、2〜3週間でかなりきつい重量になります。重すぎる重量で始めると、早い時期にディロードになります。

[{Chin Up}]：自重（追加0kg）から始めます。全セットをこなせるようになったら、ディップベルトで2.5kgずつ（kg 表記では 2.5kg にそろえています）足します。

[{Deadlift}]：最低42.5kgから始めます。バーを床から適切な高さにするため、片側に10kg以上のプレートが必要です。

## よくあるアレンジ

- **補助種目を足す**：メイン種目のあとに、押す・引く・体幹の種目を2〜3セットずつ行います。おすすめは[{Face Pull}]（15〜20回×2セット）、[{Bicep Curl}]（10〜12回×2セット）、[{Hanging Leg Raise}]（10〜15回×2セット）です。
- **チンアップができない**：自重でできるようになるまで、[{Lat Pulldown}]を8回×2セット、8回以上×1セット（AMRAP）で、同じ進め方で行います。
- **マイクロプレートがない**：上半身も2.5kgずつ増やします。ディロードは増えますが、進むことはできます。
- **デッドリフトのボリュームを増やす**：AMRAP1セットでは練習量が足りないと感じたら、ワークセットを足して、5回×2セット、5回以上×1セット（AMRAP）にします。r/FitnessのBasic Beginner Routineはこの形です。

### Phrak's Greyskull LPは初心者に向いていますか？

向いています。初心者向けのバーベルプログラムの中でも、特におすすめされているものの1つです。ほとんどの初心者向けプログラムにない、引く種目（チンアップとロウ）が毎回入っています。最後のAMRAPセットが自動調整の役目を果たし、ディロードが無駄な時間にならず、役に立つ時間になります。

### Phrak's Greyskull LPは週に何日行いますか？

週3日で、連続しない日に行います。月・水・金が基本です。2種類のワークアウト（AとB）を毎回交互に行うので、1週目はA/B/A、2週目はB/A/Bになります。

### Phrak's Greyskull LPはStarting Strengthとどう違いますか？

Phrak's GSLPは、毎回のワークアウトにチンアップとロウが入り、5回のストレートセットの代わりに最後をAMRAPセットにし、攻めの進め方（AMRAPで10回以上なら重量の増やし幅が2倍）があります。Starting Strengthは5回×3セットのストレートセットだけで、引く種目はフェーズ3まで入りません。

### Phrak's Greyskull LPで停滞したらどうしますか？

ある種目で指定のレップをすべて達成できなかったら、重量を10%下げて積み直します。軽い重量で高レップのAMRAPをこなしながら戻ると、筋肥大の刺激が入って、停滞を抜けやすくなります。ディロードは、仕組みの一部です。

### Phrak's Greyskull LPはどのくらい続けるべきですか？

2〜4か月続けてください。複数の種目で頻繁にディロードするようになり、AMRAPが5回ぎりぎりになったら、次に進みます。おすすめの次のプログラムは、[GZCLP](/programs/gzclp)や[5/3/1 for Beginners](/programs/the5314b)です。

### Phrak's Greyskull LPに補助種目を足せますか？

足せます。メイン種目のあとに、フェイスプル、バイセップカール、ハンギングレッグレイズを、10〜15回で2〜3セットずつ足してください。補助種目は軽くして、メイン種目の回復を妨げないようにします。

```liftoscript
# Week 1
## Workout A
main / used: none / 2x5, 1x5+ \
  / progress: custom(increase: 2.5lb) {~
  if (completedReps >= reps) {
    if (completedReps[ns] > 10) {
      weights += state.increase * 2
    } else {
      weights += state.increase
    }
  } else {
    weights *= 0.9
  }
~}

Overhead Press / ...main / 45lb
Chin Up / ...main / 0lb
Squat / ...main / 45lb / progress: custom(increase: 5lb) { ...main }

## Workout B
Bench Press / ...main / 45lb
Bent Over Row / ...main / 95lb
Deadlift / 1x5+ / 95lb / progress: custom(increase: 5lb) { ...main }
```
