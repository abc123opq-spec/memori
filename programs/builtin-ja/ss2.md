初心者向けのバーベルプログラムで、Starting Strengthの中心となるフェーズです。デッドリフトを1回おきにパワークリーンに置き換えて、デッドリフトの頻度を下げて回復を助けつつ、爆発的な引く動作で身体の後面の筋肉も鍛え続けます。初心者の多くがもっとも長く続けるのがこのフェーズで、2.5kgずつの増量を数か月続けるのが一般的です。

## 由来と考え方

Starting Strengthは、テキサス州ウィチタフォールズを拠点に活動する競技パワーリフターで、筋力トレーニングのコーチでもある **Mark Rippetoe** が作りました。プログラムの詳細は著書 *Starting Strength: Basic Barbell Training*（2005年初版、現在は[第3版（2011年）](https://aasgaardco.com/store/books-702/starting-strength-basic-barbell-training-3rd-edition/)）にまとめられています。姉妹書の *Practical Programming for Strength Training* では、初心者向けプログレッションの背景にある理論を扱っています。

根底にあるのは、初心者は何か月にもわたって毎回バーの重量を増やせるという考え方で、これを「ノービス効果」と呼びます。この時期をマシンや複雑なピリオダイゼーションに費やすのはもったいないと考え、Starting Strengthは少数のバーベル種目、リニアな重量増加、ワークアウト間の十分な回復でこの時期を使い切ります。筋力をもっとも基本的な身体能力と位置づけ、筋肉量、パワー、持久力は筋力が上がった結果としてついてくると考えます。

## 向いている人

- **経験**：フェーズ1（トレーニング開始から1〜3週間）を終えた初心者、またはデッドリフトの重量が重くなり、毎回行うと回復に響く初心者
- **目的**：デッドリフトの頻度を無理のない範囲に保ちながら、土台となるバーベルの筋力をつけ続けること
- **前提**：[{Squat}]、[{Bench Press}]、[{Overhead Press}]、[{Deadlift}]のフォームに不安がないこと。[{Power Clean}]を覚える意欲があること（[{Bent Over Row}]で代用してもかまいません）
- **食事**：摂取カロリーが消費を上回る状態がおすすめです。回復と成長のために食べる必要があります。維持カロリーでも進められますが、伸びが止まるのは早くなります

## メリットとデメリット

**メリット**

- 初心者としては最速の筋力アップが見込めます。毎回重量を増やせるので、2〜3か月で[{Squat}]が22.5〜45kg伸びることもあります
- 1回のワークアウトは種目が3つだけで、45〜60分で終わります
- 週3回のスクワットで、動作がすばやく身に付きます
- [{Power Clean}]で、多くの初心者向けプログラムが扱わない爆発力と、身体の後面の筋肉のパワーを養えます
- 記録が非常に充実しています。本は300ページ以上あり、すべての種目のテクニックが詳しく解説されています

**デメリット**

- 腕、上背部、腹筋を直接鍛える種目がありません。腕と腹筋はメイン種目を通じて間接的にしか成長しません
- [{Power Clean}]は技術的な難度が高く、コーチなしで覚えるのは困難です。代わりに[{Bent Over Row}]を行う初心者も多くいます
- [{Deadlift}]は1回のワークアウトで1セットだけで、しかも1回おきです。引く種目のボリュームをもっと増やしたいと思う人もいます
- [{Bench Press}]と[{Overhead Press}]は、それぞれ2週間で3回ずつしか行いません。上半身の頻度としては低めです
- 「たくさん食べる」という食事の方針を文字どおりに受け取ると、脂肪がつきすぎることがあります

## プログラムの構成

- **スプリット**：全身、A/Bの交互
- **ピリオダイゼーション**：単純なリニアプログレッション。毎回重量を増やします
- **ローテーション**：1週目はA/B/A、2週目はB/A/B、以降は繰り返し
- 週3日、連続しない日に行います（例：月・水・金）

ワークアウトAには[{Deadlift}]、ワークアウトBには[{Power Clean}]が入っています。[{Bench Press}]と[{Overhead Press}]は、2つのワークアウトで入れ替わります。

## 種目の選び方と理由

どのワークアウトも[{Squat}]から始めます。もっとも多くの筋肉量を使い、高頻度の恩恵がいちばん大きい種目だからです。週3回のスクワットで技術練習の量が最大になり、初心者の急速な伸びを支えます。

2つ目の種目は、[{Bench Press}]（水平方向のプッシュ）と[{Overhead Press}]（垂直方向のプッシュ）が交互に入ります。2つそろえることで、上半身のプレス全体の筋力が育ちます。交互にすることで、それぞれの回復時間も確保できます。

3つ目の種目は引く動作で、ワークアウトAでは[{Deadlift}]、ワークアウトBでは[{Power Clean}]を行います。フェーズ2になるとデッドリフトの重量が重くなり、毎回重く引くと、とくに次回のスクワットへの回復に響きます。パワークリーンは軽めの重量で爆発的な股関節の伸展を鍛えるので、回復の負担を抑えながら、身体の後面の筋肉を伸ばし続けられます。クリーンの爆発的な動きは、デッドリフトの筋力を間接的に引き上げる効果もあります。

**代用**：パワークリーンができない場合（コーチがいない、プラットフォームがないなど）は、[{Bent Over Row}]に替えるのがもっとも一般的です。ロウでも上背部と身体の後面の筋力はつきますが、爆発的な動きの練習は失われます。Rippetoe自身も、この代用を認めています。

## セット数とレップ数

- [{Squat}]、[{Bench Press}]、[{Overhead Press}]：**5回×3セット**。神経系の適応を促せる重さで、動作を練習するのに十分なボリュームがあります。筋力づくりの定番のレップ数です。
- [{Deadlift}]：**5回×1セット**。デッドリフトは全身への疲労がもっとも大きい種目です。初心者には、5回の重いセットを1つこなせば刺激として十分で、次回のスクワットへの回復も残せます。
- [{Power Clean}]：**3回×5セット**。クリーンは疲れるとパワーが落ちるので、3回で行います。少ないレップ数でセットを重ねることで、毎回のレップを質の高いフォームで練習できます。

すべてのセットは、同じ重量で行うストレートセットです。AMRAPセットも、バックオフセットもありません。決められたレップ数を達成したら、次回に重量を増やします。

## プログレッシブオーバーロード

**ワークアウトごとの重量の増やし方**

| 種目 | 増量 |
|------|----------|
| [{Squat}] | +2.5kg |
| [{Deadlift}] | +2.5kg |
| [{Bench Press}] | +2.5kg |
| [{Overhead Press}] | +2.5kg |
| [{Power Clean}] | +2.5kg |

上半身の種目で2.5kgずつの増量が大きすぎるようになったら（通常は数週間後）、片側0.625kg相当のマイクロプレートを使って **1.25kgずつ** に切り替えます（プログラムの増量を書き換えます）。これで[{Overhead Press}]と[{Bench Press}]のリニアプログレッションを大幅に延ばせます。

**停滞したとき**（同じ種目で、決められたレップ数を2回連続のワークアウトで達成できなかったとき）

1. その種目の現在のワークセット重量から **10%ディロード** します
2. 通常どおり、ワークアウトごとの増量で重量を戻していきます
3. ディロードを2〜3回繰り返しても伸び続けない種目は、中級者向けのプログラムが必要になっている可能性があります

種目ごとに個別に管理します。[{Overhead Press}]が停滞しても、[{Squat}]の増量には影響しません。

**ディロードの前に**回復を確認してください。睡眠は7〜9時間とれていますか。タンパク質（体重1kgあたり約1.5〜2.2g）と総カロリーは足りていますか。早い段階での停滞は、回復不足が最大の原因です。

## 続ける期間と次のプログラム

**フェーズ2は数週間から数か月続けます。** 初心者向けプログラムのなかでもっとも長いフェーズで、多くの初心者が2〜4か月ここで過ごします。

**フェーズ3に進む目安**：マイクロプレートを使っても上半身の種目が停滞し始め、引く種目のボリュームを増やすために[{Chin Up}]を加えたくなったときです。ほとんどの種目でリニアプログレッションが尽きた場合（通常は、ディロードを2〜3回繰り返しても伸びなくなったあと）は、中級者向けのプログラムに直接移ってもかまいません。

**次に進むプログラム**
- [Starting Strength Phase 3](/programs/ss3)：[{Chin Up}]が加わり、A日の[{Deadlift}]/[{Power Clean}]が交互になります
- [Texas Method](/programs/texasmethod)：自然な中級者向けの続き。ボリューム・回復・強度の日を置く、週単位のピリオダイゼーションです
- [Madcow 5x5](/programs/madcow)：ランプアップセットを使う、週単位のプログレッションです
- [5/3/1 for Beginners](/programs/the5314b)：月単位のピリオダイゼーションで、柔軟性が高く、ずっと続けられます

## 必要な器具

- バーベルとプレート
- スクワットラックまたはパワーラック
- フラットベンチ
- **マイクロプレート**（片側0.625kg相当）：1.25kgずつ増やすのに必要です。置いていないジムが多いので、自分で買ってください

[{Power Clean}]を行う場合は、バンパープレートとプラットフォームがあるのが理想ですが、必須ではありません。[{Bent Over Row}]で代用する場合は、追加の器具は要りません。

## 休憩時間

- **ウォームアップセット**：プレートを付け替えられる程度の時間（30〜60秒）
- **序盤のワークセット**：2〜3分
- **重いワークセット**：3〜5分（[{Squat}]/[{Deadlift}]の限界に近いセットは最長7分）

次のセットをやり切れるまで休んでください。休憩を急ぐことは、初心者が本来できるはずのセットを失敗する最大の原因です。

## 開始重量の決め方

フェーズ1から移る場合は、今の重量のまま続けます。[{Power Clean}]だけは最初からやり直します。

[{Power Clean}]は、空のバーから始めて、バーの動きが遅くなるまで5kgずつ重量を足していきます。開始重量は30〜42.5kgが一般的です。重量を追う前に、動作を覚えることに集中してください。

フェーズ1を飛ばして最初から始める場合は、種目ごとに次の手順で決めます。

1. 空のバー（20kg）で5回を1セット行います
2. 5〜10kg追加して、もう1セット5回を行います
3. バーの動きがはっきり遅くなるまで繰り返します
4. その重量を最初のワークセット重量にします

**思っているより軽く始めてください。** この先、2.5kgずつ増やせる期間が何か月も続きます。重く始めて早く停滞するより、軽く始めて勢いをつけるほうがずっとよい結果になります。

## よくあるアレンジ

- **[{Power Clean}]を[{Bent Over Row}]に替える**：もっとも人気のあるアレンジです。ロウでも上背部の筋力はつきますが、爆発的なパワーは鍛えられません。コーチなしで行う初心者におすすめです。
- **[{Chin Up}]を早めに加える**：Rippetoeはフェーズ3でチンアップを加えますが、上背部と上腕二頭筋を鍛えるために、ワークアウトBの最後に限界までの3セットを早めに加える人も多くいます。
- **[{Back Extension, Bodyweight}]を加える**：腰の持久力のために、ワークアウトの最後に10回×3セットを行います。
- **マイクロローディング**：[{Overhead Press}]と[{Bench Press}]で2.5kgずつの増量が大きすぎるようになったら、片側0.625kg相当の端数プレートを使って1.25kgずつに切り替えます（プログラムの増量を書き換えます）。
- **パワークリーンなしのバリエーション**：ワークアウトBの[{Power Clean}]を[{Deadlift}]の5回×1セットに替えて、毎回デッドリフトを行います。デッドリフトの重量がまだ軽く、回復できる場合だけ有効です。そうでないと、フェーズ1で起きた回復の問題に逆戻りします。

### Starting Strengthフェーズ2は初心者に向いていますか？

はい。フェーズ2はStarting Strengthの中心となるフェーズで、初心者の多くがもっとも長く続けます。目安は2〜4か月です。先にフェーズ1（1〜3週間）を終えておくか、少なくともスクワット、ベンチプレス、オーバーヘッドプレス、デッドリフトのフォームに不安がない状態にしてください。

### Starting Strengthフェーズ2は週に何日行いますか？

週3日、連続しない日（通常は月・水・金）に行います。AとBの2つのワークアウトを毎回交互に行います。ワークアウトAにはデッドリフト、ワークアウトBにはパワークリーンが入っています。

### Starting Strengthで、パワークリーンをロウに替えてもよいですか？

はい。パワークリーンの代用としては、ベントオーバーロウがもっとも一般的です。ロウでも上背部と身体の後面の筋力はつきますが、爆発的な動きの練習は失われます。Rippetoe自身も、コーチなしで行うリフターにはこの代用を認めています。

### Starting Strengthフェーズ2では、重量をどう増やしますか？

すべての種目でリニアプログレッションを使い、スクワット、デッドリフト、ベンチプレス、オーバーヘッドプレス、パワークリーンをワークアウトごとに2.5kgずつ増やします。上半身の種目で2.5kgずつの増量が大きすぎるようになったら、マイクロプレートを使って1.25kgずつに切り替えます。

### Starting Strengthフェーズ2はどのくらい続けますか？

数週間から数か月続けます。初心者の多くは、このフェーズに2〜4か月とどまります。マイクロローディングをしても上半身の種目が停滞したら次に進みます。ディロードを2〜3回繰り返しても伸びなくなったら、中級者向けのプログラムに直接移ってもかまいません。

### Starting Strengthで停滞したら、どうすればよいですか？

同じ種目で、決められたレップ数を2回連続のワークアウトで達成できなかったら、10%ディロードして重量を戻していきます。ディロードの前に回復を確認してください。睡眠を7〜9時間とり、タンパク質（体重1kgあたり約1.5〜2.2g）を十分にとります。種目ごとに個別に管理します。

```liftoscript
Bench Press / 3x5 / 45lb / progress: lp(5lb, 1, 0, 10%, 2, 0)

## Workout B
Squat / 3x5 / 45lb

Power Clean / 5x3 / 95lb / progress: lp(5lb, 1, 0, 10%, 2, 0)
```
