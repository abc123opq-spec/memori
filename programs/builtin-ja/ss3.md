初心者向けのバーベルプログラムで、Starting Strengthの上級初心者向けのフェーズです。上半身の引くボリュームを補うために[{Chin Up}]が加わります。[{Deadlift}]と[{Power Clean}]はA日のなかで交互になり、4つのワークアウトを回すローテーションになります。この段階になると、[{Overhead Press}]と[{Bench Press}]はたいてい、マイクロローディング（1.25kgずつの増量）が必要になります。

## 由来と考え方

Starting Strengthは、テキサス州ウィチタフォールズを拠点に活動する競技パワーリフターで、筋力トレーニングのコーチでもある **Mark Rippetoe** が作りました。プログラムの詳細は著書 *Starting Strength: Basic Barbell Training*（2005年初版、現在は[第3版（2011年）](https://aasgaardco.com/store/books-702/starting-strength-basic-barbell-training-3rd-edition/)）にまとめられています。姉妹書の *Practical Programming for Strength Training* では、初心者向けプログレッションの背景にある理論を扱っています。

根底にあるのは、初心者は何か月にもわたって毎回バーの重量を増やせるという考え方で、これを「ノービス効果」と呼びます。この時期をマシンや複雑なピリオダイゼーションに費やすのはもったいないと考え、Starting Strengthは少数のバーベル種目、リニアな重量増加、ワークアウト間の十分な回復でこの時期を使い切ります。筋力をもっとも基本的な身体能力と位置づけ、筋肉量、パワー、持久力は筋力が上がった結果としてついてくると考えます。

## 向いている人

- **経験**：フェーズ1と2を終えた初心者のリフター（通常はトレーニング開始から2〜4か月）
- **目的**：中級者向けのプログラムに移る前に、初心者向けのリニアプログレッションの伸びを最後まで引き出すこと
- **前提**：フェーズ2の5つの種目すべてでフォームが安定していること。2.5kgずつの増量では、上半身の種目が伸び悩み始めていること
- **食事**：摂取カロリーが消費を上回る状態が引き続きおすすめです。このフェーズでは、どの種目も自己ベストに近い重量になるので、回復への要求がもっとも高くなります

## メリットとデメリット

**メリット**

- [{Chin Up}]が、不足していた上半身の引くボリュームを補います。背中の発達と上腕二頭筋の筋力が向上します
- A日で[{Deadlift}]と[{Power Clean}]を交互にするので、どちらの動作も保ちながら疲労を抑えられます
- マイクロローディングで、2.5kgずつの増量なら停滞していたはずの時点から、上半身のリニアプログレッションをさらに数週間延ばせます
- 構成は引き続きシンプルです。1回のワークアウトは種目が3つで、週3日です

**デメリット**

- 4つのワークアウトのローテーションは、フェーズ2のシンプルなA/Bの交互より、管理が複雑です
- 腕、腹筋、三角筋の中部を直接鍛える種目がありません。[{Chin Up}]で上腕二頭筋には効きますが、アイソレーション種目は引き続きありません
- [{Bench Press}]と[{Overhead Press}]は、それぞれ4回のワークアウトで3回しか行いません。フェーズ2よりさらに頻度が低くなります
- 初心者としての伸びが終わりに近づいているので、進歩は目に見えて遅くなり、停滞も増えます
- 原文は上半身の種目に片側0.625kg相当のマイクロプレートを前提にしています（このアプリでは2.5kgずつにそろえています）。置いていないジムが多くあります

## プログラムの構成

- **スプリット**：全身、4つのワークアウトのローテーション
- **ピリオダイゼーション**：単純なリニアプログレッション。毎回重量を増やします
- **ローテーション**：4つのワークアウト（A1、B1、A2、B2）を繰り返します。週3回のため、曜日の割り当ては毎週ずれていきます
- 週3日、連続しない日に行います（例：月・水・金）

プレスとベンチの交互、デッドリフトとパワークリーンの交互は、ここから**互いに独立**します。その結果、4つの異なるワークアウトができます。

| ワークアウト | 種目1 | 種目2 | 種目3 |
|---------|--------|--------|--------|
| A1 | [{Squat}] | [{Bench Press}] | [{Deadlift}] |
| B1 | [{Squat}] | [{Overhead Press}] | [{Chin Up}] |
| A2 | [{Squat}] | [{Overhead Press}] | [{Power Clean}] |
| B2 | [{Squat}] | [{Bench Press}] | [{Chin Up}] |

月・水・金で行う場合の、3週間分のローテーションの例です。

| | 月曜 | 水曜 | 金曜 |
|---|--------|-----------|--------|
| 1週目 | A1 | B1 | A2 |
| 2週目 | B2 | A1 | B1 |
| 3週目 | A2 | B2 | A1 |

## 種目の選び方と理由

[{Squat}]は、引き続きすべてのワークアウトの最初に行います。フェーズ3ではスクワットのフォームが安定し、重量も重くなっているので、疲れていない状態で臨む必要があります。

[{Bench Press}]と[{Overhead Press}]は引き続き交互に行いますが、2つのワークアウトではなく、4つのワークアウトのサイクルで回します。それぞれのプレスは、およそ週1回です。フェーズ2より頻度は低くなりますが、この段階では重量が重くなっているので、プレスの間に回復の時間を多くとるほうが有益です。

[{Deadlift}]と[{Power Clean}]は、**どちらも**A日にだけ入り、交互に行います。デッドリフトの頻度はさらに下がります（フェーズ2ではA日のたびでしたが、ここではA日の1回おきです）。デッドリフトの重量が、リフターの能力に対してとても重くなっているので、これは必要なことです。

[{Chin Up}]は新しく加わる種目で、B日のすべてに入ります。これまでのプログラムには、デッドリフトとクリーン以外に、上背部を直接鍛える引く種目がなく、その穴を埋めます。チンアップは広背筋、上腕二頭筋、前腕を鍛え、その筋力はデッドリフトのロックアウトやベンチプレスの安定性にも生きてきます。

**代用**：[{Chin Up}]を10回×3セットこなせない場合は、できるようになるまで[{Lat Pulldown}]（10回×3セット）か、バンドで補助したチンアップを行います。[{Power Clean}]の代わりに[{Bent Over Row}]を行っている場合も、そのまま続けられます。

## セット数とレップ数

- [{Squat}]、[{Bench Press}]、[{Overhead Press}]：**5回×3セット**。前のフェーズと同じです。
- [{Deadlift}]：**5回×1セット**。前のフェーズと同じです。
- [{Power Clean}]：**3回×5セット**。フェーズ2と同じです。
- [{Chin Up}]：**10回×3セット**。自重のチンアップは負担が小さいので、ほかの種目よりレップ数を多くします。自重で10回×3セットをこなせるようになったら、ディップベルトで重量を加え、チンアップの日を1回おきに5回×3セットにします。

## プログレッシブオーバーロード

**ワークアウトごとの重量の増やし方**

| 種目 | 増量 |
|------|----------|
| [{Squat}] | +2.5kg |
| [{Deadlift}] | +2.5kg |
| [{Bench Press}] | +2.5kg（kg 表記では 2.5kg にそろえています） |
| [{Overhead Press}] | +2.5kg（kg 表記では 2.5kg にそろえています） |
| [{Power Clean}] | +2.5kg（kg 表記では 2.5kg にそろえています） |
| [{Chin Up}] | +2.5kg（加重チンアップになってから） |

フェーズ3では、原文は上半身の種目を1.25kgずつ増やす**マイクロローディング**を前提にしています。このアプリのkg表記では2.5kgずつにそろえているので、[{Overhead Press}]と[{Bench Press}]は早めに停滞しやすくなります。

**停滞したとき**（同じ種目で、決められたレップ数を2回連続のワークアウトで達成できなかったとき）

1. その種目の現在のワークセット重量から **10%ディロード** します
2. 通常どおり、ワークアウトごとの増量で重量を戻していきます
3. ディロードを2〜3回繰り返しても伸び続けない種目は、初心者向けのリニアプログレッションを終えたことになります。その種目は中級者向けのプログラムに移します

種目ごとに個別に管理します。[{Overhead Press}]のリニアプログレッションが、[{Squat}]より何か月も早く終わることもあります。プログラムを変えるのは、本当に停滞した種目だけにしてください。

## 続ける期間と次のプログラム

**フェーズ3は、リニアプログレッションが尽きるまで続けます。** 通常は、このフェーズに入ってから数週間から2か月ほどです。Starting Strengthの初心者向けプログラム全体（すべてのフェーズの合計）では、通常**3〜9か月**です。

**次に進む目安**：睡眠も栄養も足りているのに、[{Squat}]と[{Deadlift}]で何度もディロードしている状態です。複数の種目が、ディロードを2〜3回繰り返しても停滞しています。

**次に進むプログラム**
- [Texas Method](/programs/texasmethod)：Rippetoeがすすめる自然な続き。ボリューム・回復・強度の日を置く、週単位のピリオダイゼーションです
- [Madcow 5x5](/programs/madcow)：ランプアップセットを使う、同じような週単位のプログレッションです
- [5/3/1 for Beginners](/programs/the5314b)：月単位のピリオダイゼーションで、柔軟性が高く、ずっと続けられます
- [GZCLP](/programs/gzclp)：ティアに分けた構成で、種目のバリエーションが増えます

## 必要な器具

- バーベルとプレート
- スクワットラックまたはパワーラック
- フラットベンチ
- 懸垂バー（代わりに[{Lat Pulldown}]のマシンでもかまいません）
- **マイクロプレート**（片側0.625kg相当）：原文ではフェーズ3で欠かせません（このアプリでは2.5kgずつにそろえています）。置いていないジムが多いので、自分で買ってください
- 加重[{Chin Up}]用のディップベルト（自重が楽になってから）

[{Power Clean}]を行う場合は、バンパープレートとプラットフォームがあるのが理想ですが、必須ではありません。

## 休憩時間

- **ウォームアップセット**：プレートを付け替えられる程度の時間（30〜60秒）
- **序盤のワークセット**：2〜3分
- **重いワークセット**：3〜5分（[{Squat}]/[{Deadlift}]の限界に近いセットは最長7分）
- **チンアップ**：セット間は2〜3分

次のセットをやり切れるまで休んでください。フェーズ3の重量では、休憩時間をしっかりとる必要があります。急がないでください。

## 開始重量の決め方

フェーズ2から移る場合は、今ある種目の重量をそのまま続けます。[{Chin Up}]は自重（追加0kg）から始めます。

フェーズ3から最初に始める場合（おすすめしません。フェーズ1から始めてください）は、種目ごとに次の手順で決めます。

1. 空のバー（20kg）で5回を1セット行います
2. 5〜10kg追加して、もう1セット5回を行います
3. バーの動きがはっきり遅くなるまで繰り返します
4. その重量を最初のワークセット重量にします

## よくあるアレンジ

- **軽いスクワットの日**：上級初心者のなかには、回復を助けるために、真ん中のトレーニング日に軽めのスクワット（ワーク重量の80%、5回×2セット）を加える人もいます。*Practical Programming* にある「上級初心者」向けのアレンジです。
- **加重チンアップ**：自重で10回×3セットをこなせるようになったら、B日ごとに、自重で限界までのチンアップと、加重5回×3セットのチンアップを交互に行います。
- **[{Power Clean}]を[{Bent Over Row}]に替える**：フェーズ3でも有効です。5回×3セットか3回×5セットのロウがよく合います。
- **補助種目を加える**：この段階になると、メイン種目のあとに軽い補助種目を1〜2種目加える人もいます。[{Back Extension, Bodyweight}]（10回×3セット）、[{Bicep Curl}]（10回×3セット）、[{Hanging Leg Raise}]（10回×3セット）などです。重量は軽くして、メイン種目の回復の妨げにならないようにしてください。
- **限界に近い種目は3回×3セットや1回×5セットに落とす**：5回目をいつも達成できなくなったら、コーチによっては、中級者向けのプログラムに移る前に、重量を上げて3回や1回のセットに一時的に切り替え、伸ばし続けることをすすめます。

<!-- faq -->

### Starting Strengthフェーズ3は最後のフェーズですか？

はい。フェーズ3は上級初心者向けのフェーズで、中級者向けのプログラムに移る前の最終段階です。チンアップが加わり、4つのワークアウトのローテーションになります。Starting Strengthのすべてのフェーズの合計は、通常3〜9か月です。

### Starting Strengthフェーズ3は週に何日行いますか？

引き続き、連続しない日（通常は月・水・金）に行う週3日のプログラムです。ただし、フェーズ2のシンプルなA/Bの交互ではなく、4つのワークアウトのローテーションになります。4つのワークアウトを繰り返し、曜日の割り当ては毎週ずれていきます。

### Starting Strengthフェーズ3は何が違いますか？

フェーズ3では、上半身の引くボリュームを補うために、B日のすべてにチンアップが加わります。デッドリフトとパワークリーンは、決まったワークアウトに固定されず、A日のなかで交互になります。上半身の種目では、マイクロローディング（1.25kgずつの増量）が欠かせなくなります。

### Starting Strengthフェーズ3にマイクロプレートは必要ですか？

はい。原文は、マイクロプレート（片側0.625kg相当、合計1.25kgずつの増量用）を前提にしています。このアプリのkg表記では2.5kgずつにそろえているので、なくても進められますが、オーバーヘッドプレスとベンチプレスは早めに停滞しやすくなります。

### Starting Strengthのあとは、どのプログラムを行えばよいですか？

自然な続きは[Texas Method](/programs/texasmethod)（ボリューム・回復・強度の日を置く、週単位のピリオダイゼーション）です。ほかに、[Madcow 5x5](/programs/madcow)（ランプアップセットを使う、週単位のプログレッション）、[5/3/1 for Beginners](/programs/the5314b)（月単位のピリオダイゼーション）、[GZCLP](/programs/gzclp)（ティアに分けた構成で、バリエーションが豊富）などがよい選択肢です。

### Starting Strengthフェーズ3をやめて次に進むのは、いつですか？

睡眠も栄養も足りているのに、スクワットとデッドリフトで何度もディロードしていて、複数の種目がディロードを2〜3回繰り返しても停滞しているときです。オーバーヘッドプレスのリニアプログレッションは、スクワットより何か月も早く終わることがあります。プログラムを変えるのは、本当に停滞した種目だけにしてください。

```liftoscript
# Week 1
## Day A 1
Squat / 3x5 / 45lb / progress: lp(5lb, 1, 0, 10%, 2, 0)
Bench Press / 3x5 / 45lb / progress: lp(2.5lb, 1, 0, 10%, 2, 0)
Deadlift / 1x5 / 95lb / progress: lp(5lb, 1, 0, 10%, 2, 0)

## Day B 1
Squat / 3x5 / 45lb
Overhead Press / 3x5 / 45lb / progress: lp(2.5lb, 1, 0, 10%, 2, 0)
Chin Up / 3x10 / 0lb / progress: lp(2.5lb, 1, 0, 10%, 2, 0)

## Day A 2
Squat / 3x5 / 45lb
Overhead Press / 3x5 / 45lb
Power Clean / 5x3 / 95lb / progress: lp(2.5lb, 1, 0, 10%, 2, 0)

## Day B 2
Squat / 3x5 / 45lb
Bench Press / 3x5 / 45lb
Chin Up / 3x10 / 0lb
```
