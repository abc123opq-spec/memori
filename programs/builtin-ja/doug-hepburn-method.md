Doug Hepburnのパワーパンプ式は、各メイン種目で、重い低レップのセットと、中程度のやや高レップのセットを組み合わせます。2回×8セットから始め、ワークアウトごとに1回ずつ足して、3回×8セットまで進めます。全セットが3回になったら重量を上げ、また2回から始めます。スクワット、ベンチプレス、デッドリフト、オーバーヘッドプレスを週2回ずつ行い、引く動作のバランスのためにチンアップとベントオーバーロウを加えます。

## 成り立ちと考え方

Doug Hepburn（1926〜2000）はカナダのストロングマンで、重量挙げの選手でもあります。1953年の世界選手権で優勝しました。ベンチプレスで約227kgを挙げた史上初の人物で、スクワットは272kg超、ストリクトカールは約102kgを挙げています。しかも、すべてドラッグフリーで、現代のトレーニング科学が確立する前の時代の記録です。

Hepburnは、最大に満たない重量で高頻度に練習することで筋力が育つと考えていました。全力で粘り抜くセットは1つもありません。重い重量（1RMの80%）を扱いますが、常に余力を残します。進歩は、ワークアウトごとに1回足すだけです。ほとんど気づかないほどの小さな積み重ねですが、8回のワークアウトで効いてきます。2回×8セットで始めたものが3回×8セットになり、同じ重量で総ボリュームが50%増えます。そこで重量を上げて、また最初からやり直します。

この方法には2つの要素があります。**パワー**（最大筋力のための、重い2回・3回）と**パンプ**（筋肥大と回復のための、6〜8回の中程度のセット）です。どちらも同じ、小刻みな進め方をします。このプログラムは、パンプのボリュームを減らした、広く勧められている形に従っています。Hepburnのオリジナルは限界まで6セットですが、ここでは3セットです。ほとんどの人にとって、こちらのほうが長く続けられます。

## 向いている人

- **経験**：中級者から上級者（本格的なバーベルトレーニングを1年以上）。1種目につき8セット、最大の80%を扱うので、[{Squat}]、[{Bench Press}]、[{Deadlift}]、[{Overhead Press}]のフォームが安定している必要があります。
- **目的**：主に筋力。パンプのフェーズで、筋肥大も少し狙えます。筋肉の成長を最大にしたいなら、代わりに[PHUL](/programs/phul)か[PHAT](/programs/phat)を検討してください。
- **理想的な使い方**：持続可能な筋力向上を長い目で狙う、気長なリフター。ケガから復帰するリフター（最大に満たない重量なので、関節に優しい進め方です）。疲労を慎重に管理したい、年齢の高いリフター。

## メリットとデメリット

**メリット**

- どのセットも最大に満たない重量なので、粘り抜くレップがありません。何か月も続けられ、関節への負担も軽くなります。
- 1回のワークアウトで1種目につき重いセットを8回行うので、セットアップとフォームの練習を、1種目あたり週に16回以上積めます。これだけ重い重量の練習量を確保できるプログラムは、あまりありません。
- 進め方はとても単純です。ワークアウトごとに1回足し、目標に届いたら重量を足します。パーセンテージの再計算も、表計算もいりません。
- 本当の意味での最大努力がないので、年齢の高いリフターや、しつこい故障を抱えている人にも向いています。

**デメリット**

- 1回のワークアウトは80〜100分かかります。メイン種目が2つあり、休憩3〜5分のパワーセット8回が時間の大半を占めます。
- バーの重量が上がるのは、種目ごとに4週間に1回だけです（パワーサイクルは8回のワークアウトで完了）。毎回重量を足すことに慣れていると、やる気が出にくくなります。
- [{Deadlift}]のボリューム（重いセット8回を週2回）は非常に多く、燃え尽きの原因になります。このプログラムを実践した人から最も多く出る不満です。
- 補助種目はごくわずかです。腕、三角筋中部、ハムストリングスの直接的な種目が必要なら、自分で足してください。

## プログラムの構成

- **スプリット**：1回のワークアウトで、上半身と下半身のコンパウンド種目を1つずつ行い、引く種目の補助種目を加えます。A/Bのローテーションを、週に2回繰り返します。
- **ピリオダイゼーション（期分け）**：サイクルごとに、負荷を自己調整するリニアプログレッションです。サイクルが終わるまでレップ数を少しずつ増やし（パワーは2回から3回、パンプは6回から8回）、終わったら重量を上げてレップ数を戻します。
- **スケジュール**：週4日。1日目と3日目は[{Squat}]＋[{Bench Press}]、2日目と4日目は[{Deadlift}]＋[{Overhead Press}]。どの種目も週2回です。

## 種目の選び方と理由

メインの4種目は、Hepburnが元々選んだものです。種目数を増やして中程度の努力で行うより、少数の種目を徹底的に極めるべきだと考えていました。[{Squat}]と[{Deadlift}]で下半身と、身体の後面の筋群を鍛えます。[{Bench Press}]と[{Overhead Press}]は、水平方向と垂直方向のプレスです。

引く動作のバランスのために、[{Chin Up}]と[{Bent Over Row}]を足しています。Hepburnのオリジナルのプログラムには、専用の背中の種目がありませんでした。ベンチプレスやプレスを頻繁に行うリフターには、問題になる点です。この2つは補助種目として、ダブルプログレッションで組んであり、進め方を単純に保てます。

Hepburnは、オリジナルのプログラムに[{Bicep Curl, Barbell}]も入れていました。ストリクトカールで100kgを挙げたことで有名です。腕の直接的な種目を優先したいなら、どのワークアウトの最後にも、バーベルカールを8〜12回×3セット足せます。

## セットとレップの組み方

**パワーフェーズ**（1RMの約80%で8セット）：重いワークセットです。各サイクルは、2回×8セット（合計16回）から始めます。ワークアウトごとに、1セットが2回から3回に上がります。8回のワークアウトのあとは、全セットが3回（合計24回）です。同じ重量でボリュームが50%増えます。このボリュームの増加が、筋力の適応を引き起こす原動力です。

**パンプフェーズ**（1RMの約65%で3セット）：同じ種目のパワーセットの直後に行う、中程度の筋肥大向けのセットです。各サイクルは、6回×3セット（合計18回）から始めます。ワークアウトごとに、1セットが1回ずつ増えます。流れは次のとおりです。6回×3セット→7回×1セット＋6回×2セット→7回×2セット＋6回×1セット→7回×3セット→8回×1セット＋7回×2セット→8回×2セット＋7回×1セット→8回×3セット（合計24回）。軽い重量で、同じ小刻みな進め方をします。

どちらのフェーズも、コントロールを保って行います。パワーの2回は重くても、切れのある動きで行ってください。気合いを入れないと挙がらない、あるいはフォームが崩れるなら、重すぎます。パンプのセットは、2〜3回の余力を残します。

## プログレッシブオーバーロード

**パワーサイクル（8回のワークアウト）**：2回×8セットから始めます。全セットをこなすたびに、2回のセットが1つ3回になります。8回成功すると、3回×8セットに達します。重量を上げて（[{Bench Press}]と[{Overhead Press}]は2.5kg、[{Squat}]と[{Deadlift}]は5kg）、2回×8セットからやり直します。

**パンプサイクル（7回のワークアウト）**：6回×3セットから始めます。全セットをこなすたびに、1セットが1回増えます。8回×3セットに達したら、パワーと同じ刻みで重量を上げ、6回×3セットからやり直します。パンプサイクルはパワーサイクルより少し短く、2つは別々に進みます。

**失敗したとき**：指定のレップをこなしきれなかったら、次回、まったく同じワークアウトをやり直します。ディロードもリセットもなく、もう一度試すだけです。最大に満たない重量なので、開始重量を正しく選んでいれば、失敗はめったにありません。

**期待できる伸び**：パワーサイクルを1回終えるごとに、各種目で2.5〜5kg伸びます。各種目は約4週間（週2回で8回のワークアウト）で1サイクル回るので、1か月に約2.5〜5kg、順調なら1年で種目あたり30〜60kgになります。

## どのくらい続けるか・次のプログラム

意味のある結果を得るには、Hepburnメソッドを最低**3〜6か月**続けてください。1年以上続ける人も多くいます。進歩がゆっくり着実なので、速いプログラムに比べて停滞するまでに時間がかかります。

**切り替えのサイン**：重量を10%下げてもサイクルを完了できないことが続く、または90分以上のワークアウトに燃え尽きてしまう。

**移行先**：似た考え方で、より構造化されたプログラムなら[5/3/1: Boring But Big](/programs/the531bbb)。月ごとのサイクルではなく毎週の自己ベスト更新を狙うなら[Texas Method](/programs/texasmethod)。ランプアップのセットで毎週重量を上げるなら[Madcow 5x5](/programs/madcow)。

## 必要な器具

- バーベル、プレート、スクワットラック、ベンチ
- 0.5kgのマイクロプレートがあると、[{Overhead Press}]で役立ちます。数サイクルを重ねると、2.5kgの増量は大きすぎることがあるためです。
- [{Chin Up}]用の懸垂バー

**自宅ジムでの代替**：懸垂バーがないときは、[{Chin Up}]を[{Inverted Row}]に替えます。[{Bent Over Row}]は、器具に合わせて、どんなロウのバリエーションでもかまいません。

## 休憩時間

- **パワーセット**：3〜5分。重い2回・3回なので、完全に回復するまで休みます。重いセットの休憩を急ぐと、最大に満たない重量で行う意味がなくなります。
- **パワーとパンプのあいだ**：約5分。重量を落とし、息を整えて、準備し直します。
- **パンプセット**：2分。重量が軽いので、休憩も短くなります。
- **補助種目**：2分

## 開始重量の決め方

**パワーフェーズ**：アプリは1RMの80%を使います。8セットとも、きつすぎるセットが1つもなく、無理なく2回できる重量のはずです。1RMがわからないときは、8RMを使ってください。最大のおよそ80%にあたります。

**パンプフェーズ**：アプリは1RMの65%を使います。6回のセットで、中程度に感じる重量です。きついですが、限界には近くありません。

**よくある間違い**：重すぎる重量から始めることです。最初のワークアウト（2回×8セット）は、ほとんど楽に感じるはずです。2回がきついなら、アプリで1RMの推定値を下げてください。負荷は、進めるうちに自然に上がります。

## よくあるアレンジ

- **デッドリフトのボリュームを減らす**：最も多い調整です。[{Deadlift}]のパワーセットを8セットから5セットに減らします。または、デッドリフトのワークアウトの1回を、[{Deficit Deadlift}]か、軽めの[{Romanian Deadlift, Barbell}]に替えます。
- **もっと速く進める**：ワークアウトごとに1回ではなく2回足します（毎回2つのセットを2回から3回にします）。パワーサイクルが8回から4回のワークアウトに縮まります。重量の増加が速くても対応できる、早い時期の中級者に向いています。
- **サーキット形式のパンプセット**：パンプフェーズを、引く種目や体幹の種目とスーパーセットにして、時間を節約します。たとえば、[{Bench Press}]のパンプを、[{Bent Over Row}]と[{Ab Wheel}]とスーパーセットにし、種目間の休憩を1分にします。
- **補助種目を足す**：ワークアウトの最後に、[{Face Pull}]、[{Lateral Raise}]、[{Bicep Curl, Barbell}]を2〜3セット足します。ボリュームは少なく抑え、メイン種目を中心に保ってください。
- **週3日の変形**：1週目はA/B/A、2週目はB/A/Bで回します。各種目は、2週間に4回ではなく3回鍛えます。進歩は遅くなりますが、回復は楽になります。

### Hepburnメソッドは初心者に向いていますか？

向いていません。初心者は、もっと単純なプログラムで毎回重量を足せるので、Hepburnのゆっくりした小刻みな進め方は必要ありません。まず初心者向けのリニアプログレッションのプログラムから始め、ワークアウトごとの重量アップが通用しなくなったらHepburnに移ってください。

### Hepburnメソッドは週何日ですか？

週4日です。1回のワークアウトで、上半身と下半身の種目を1つずつ組み合わせます（2日はスクワット＋ベンチプレス、残りの2日はデッドリフト＋オーバーヘッドプレス）。どの種目も週2回鍛えます。

### Hepburnメソッドのワークアウトは何分かかりますか？

1回につき80〜100分を見込んでください。種目ごとに、休憩3〜5分のパワーセット8回が時間の大半を占めます。スクワットやデッドリフトの日は、オーバーヘッドプレスのような軽い種目の日より長くなりがちです。

### Hepburnメソッドでワークアウトに失敗したらどうしますか？

次回、同じレップ数・同じ重量で、同じワークアウトをやり直します。同じ段階で2〜3回続けて失敗するなら、開始重量が重すぎたということです。アプリで1RMの推定値を下げ、サイクルをやり直してください。

### Hepburnメソッドでは、どのくらいの速さで筋力が伸びますか？

パワーサイクルを1回終えるごとに、各種目で2.5〜5kg伸びます。1サイクルは約4週間（週2回で8回のワークアウト）です。年間では、種目あたり約30〜60kgになります。上半身の種目は1サイクルで2.5kg、下半身は5kgが目安です。

### 減量中にHepburnメソッドを行えますか？

できなくはありませんが、理想的ではありません。重いセットのボリュームが多いので、十分な回復が必要です。カロリー不足の状態では、開始重量を軽めにし（パワーを80%ではなく75%）、進歩を気長に待つことを検討してください。

### Hepburnの著書にある版と、このプログラムはどう違いますか？

Hepburnの著書では、パンプのフェーズは限界までの6回×6セットで、さらにパンプのセットを加えます。ボリュームが非常に多く、ほとんどの人は燃え尽きます。このプログラムのパンプは、6〜8回×3セットです。経験のある実践者の多くが勧めている形です。

### Hepburnメソッドを1つの種目だけに使えますか？

使えます。1〜2種目（ベンチプレスやオーバーヘッドプレスが多い）だけをHepburn式のプログレッションで進め、残りは別のプログラムで行う人は多くいます。1つの種目を重点的に伸ばす専門化ブロックとしても、よく機能します。

```liftoscript
# Week 1
## Day 1

// **Power** - Doubles building to triples. When all 8 sets hit 3 reps, add weight and reset.
hepburn / used: none / 8x2 / 80% / 180s / progress: custom(min: 2, max: 3, increment: 10lb) {~
  if (completedReps >= reps) {
    if (min(reps) == max(reps) && max(reps) == state.max) {
      reps = state.min
      weights += state.increment
    } else {
      var.stop = 0
      for (var.i in completedReps) {
        if (var.stop == 0 && reps[var.i] < max(reps)) {
          var.stop = 1
          reps[var.i] += 1
        }
      }
      if (var.stop == 0) {
        reps[1] += 1
      }
    }
  }
~}

// ...hepburn
power: Squat / ...hepburn
// **Pump** - Sets of 6 building to 8. When all 3 sets hit 8 reps, add weight and reset.
pump: Squat / 3x6 / 65% / 120s / warmup: none / progress: custom(min: 6, max: 8) { ...hepburn }
// ...hepburn
power: Bench Press / ...hepburn / progress: custom(increment: 5lb) { ...hepburn }
// **Pump** - Sets of 6 building to 8. When all 3 sets hit 8 reps, add weight and reset.
pump: Bench Press / 3x6 / 65% / 120s / warmup: none / progress: custom(min: 6, max: 8, increment: 5lb) { ...hepburn }
Chin Up / 3x8 / 0lb / 120s / warmup: none / progress: dp(5lb, 8, 12)

## Day 2
// ...hepburn
power: Deadlift / ...hepburn
// **Pump** - Sets of 6 building to 8. When all 3 sets hit 8 reps, add weight and reset.
pump: Deadlift / 3x6 / 65% / 120s / warmup: none / progress: custom(min: 6, max: 8) { ...hepburn }
// ...hepburn
power: Overhead Press / ...hepburn / progress: custom(increment: 5lb) { ...hepburn }
// **Pump** - Sets of 6 building to 8. When all 3 sets hit 8 reps, add weight and reset.
pump: Overhead Press / 3x6 / 65% / 120s / warmup: none / progress: custom(min: 6, max: 8, increment: 5lb) { ...hepburn }
Bent Over Row / 3x8 / 95lb / 120s / progress: dp(5lb, 8, 12)
```
