[GZCLメソッド](http://swoleateveryheight.blogspot.com/2016/02/gzcl-applications-adaptations.html)をもとにした、定番のリニアプログレッションのプログラムです。種目の選び方のバランスがよく、実績のある進め方が組まれています。初心者に向いていて、[ベーシックビギナー](/programs/basicBeginner)を3〜6か月やった直後に選べます。

<!-- more -->

GZCLPは、**GZCLの原則**にもとづくウェイトトレーニングのプログラムで、[Cody Lefever](https://www.gainzfever.com/)が考案しました。GZCLという名前は、彼のRedditのユーザー名[u/gzcl](https://www.reddit.com/u/gzcl)に由来します。初心者向けのプログラムで、週3日行います。[ベーシックビギナールーティン](/programs/basicBeginner)やStarting Strengthを3〜6か月行ったあとの、次の一歩としてよい選択です。ほかの初心者向けプログラムよりレップ数が多いので、種目の練習量を確保したい場合にも向いています。

## GZCLの原則

詳しく入る前に、基本の用語を押さえます。

- **レップマックス（RM）**：決まったレップ数でできる最大の重量です。たとえば100kgで5回しかできないなら、5RMは100kgです。測るときは完全な限界まで追い込まず、フォームを保てなくなる手前で止めてください。

次に、種目の分け方です。GZCLのプログラムでは、種目を**3つのティア**に分けます。

- **T1**：メインのコンパウンド種目です（例：[{Squat}]、[{Deadlift}]、[{Bench Press}]、[{Overhead Press}]）。強度は最も高く（2〜3RMの**85〜100%**ほどの重い重量）、ボリュームは少なめです（レップ数もセット数も少なめ）。合計で10〜15回が目安で、多くは1セットあたり**1〜3回**です。
- **T2**：サブのコンパウンド種目です（例：[{Front Squat}]、[{Romanian Deadlift}]、[{Incline Bench Press}]など）。T1より強度は低く（軽い重量）、ボリュームは多くなります（レップ数もセット数も多め）。T1を補助する種目を選んでください。2〜3RMの**65〜85%**で、多くは1セットあたり**5〜8回**です。
- **T3**：アイソレーション種目です（例：[{Leg Press}]、[{Seated Leg Curl}]、[{Triceps Extension}]、[{Lateral Raise}]）。強度は最も低く（最も軽い重量）、ボリュームは最も多くなります（レップ数もセット数も多め）。2〜3RMの**65%未満**で、多くは1セットあたり**8回以上**です。

覚えやすい目安として、**1:2:3のルール**があります。T1で1回行うごとに、T2で2回、T3で3回行います。

ここで書いたのはGZCLの原則の短い説明です。詳しくは、[Codyのブログ記事](http://swoleateveryheight.blogspot.com/2012/11/the-gzcl-method-for-powerlifting.html)をぜひ読んでください。

## GZCLの原則をGZCLPに当てはめる

GZCLPは週3日ですが、ワークアウトはA1、A2、B1、B2の4種類あります。たとえば月曜にA1、水曜にA2、金曜にB1を行い、翌週の月曜はB2から始めます。この4つを順番に回していきます。

**T1の種目**には、メインリフトの[{Squat}]、[{Deadlift}]、[{Bench Press}]、[{Overhead Press}]を使います。最初は3回×5セットで、最後の1セットだけ限界までのレップ数（AMRAP）にします。ただし**出し切らないでください**。あと**1〜2回**できる余力を残して止めます。バーのスピードがはっきり落ちる、フォームが崩れ始める、といった状態が限界の目安です。

全セットをこなせたら、[{Bench Press}]と[{Overhead Press}]は**2.5kg**、[{Squat}]と[{Deadlift}]は**5kg**増やします。こなせなかった場合は重量を据え置いたまま、「ステージ2」（2回×6セット）に進みます。以降も同じルールで重量を増やしていきます。それでもこなせなければ、「ステージ3」（1回×10セット）に進みます。

「ステージ3」もこなせなかった場合は、新しい5RMを測ってその重量で「ステージ1」からやり直すか、現在の重量を10%下げて「ステージ1」に戻します。

まとめると、次のとおりです。

- **ステージ1**：3回×5セット。最後のセットはAMRAP
- **ステージ2**：2回×6セット。最後のセットはAMRAP
- **ステージ3**：1回×10セット。最後のセットはAMRAP

**T2の種目**にも、T1と同じメインリフトの[{Squat}]、[{Deadlift}]、[{Bench Press}]、[{Overhead Press}]を使います。スクワットをT1で行う日は、ベンチプレスをT2で行います。ベンチプレスがT1の日は、スクワットがT2です。T1とT2を交互に入れ替えます。

T2にも3つのステージがありますが、最後のセットはAMRAPにしません。プログレッションのルールはT1と同じです。全セットをこなせたら、[{Bench Press}]と[{Overhead Press}]は**2.5kg**、[{Squat}]と[{Deadlift}]は**5kg**増やします。こなせなかった場合は、次のステージに進みます。

ステージは次のとおりです。

- **ステージ1**：10回×3セット。AMRAPなし
- **ステージ2**：8回×3セット。AMRAPなし
- **ステージ3**：6回×3セット。AMRAPなし

「ステージ3」もこなせなかった場合は、「ステージ1」のときの最後の重量に戻して7.5kg足し、「ステージ1」からやり直します。

**T3の種目**には、[{Lat Pulldown}]と[{Bent Over Row}]を使います。

ステージはありません。15回×3セットを行い、最後のセットはAMRAPにします。

25回以上できるようになったら、重量を2.5kg増やします。

これもあくまで概要です。詳しい内容は、[GZCLの応用についての元の記事](https://swoleateveryheight.blogspot.com/2016/02/gzcl-applications-adaptations.html)を読んでください。

### GZCLPは初心者に向いていますか？

はい。GZCLPは、初心者向けのプログラムのなかでも特におすすめの一つです。Starting Strengthやベーシックビギナーのような、もっとシンプルなプログラムを3〜6か月行ったあとに向いています。トレーニングの組み立て方を学べるティアの仕組み（T1/T2/T3）があり、レップ数も多いので、各種目の練習量も確保できます。

### GZCLPは週何日ですか？

週3日のプログラムです。A1、A2、B1、B2の4つのワークアウトを順番に回し、週3日、間に休養日を挟んで行います。月・水・金が一般的なスケジュールです。

### GZCLPはどのくらい続けるのがよいですか？

多くの人は3〜6か月続けます。リニアな進歩（毎回重量を増やすこと）ができなくなったら、切り替えどきです。そのときは、GZCL The RipplerやGZCL Jacked & Tan 2.0のような中級者向けのプログラムに移ってください。

### GZCLPで停滞したらどうしますか？

GZCLPには、停滞に対応する仕組みが組み込まれています。ステージをこなせなかったら、次のステージに進みます。ステージ1（3回×5セット）、ステージ2（2回×6セット）、ステージ3（1回×10セット）の順です。ステージ3もこなせなかった場合は、現在の重量の90%に下げてステージ1からやり直すか、新しい5RMを測ります。

### GZCLPに補助種目を足せますか？

はい。基本のプログラムは1日あたりT3が1種目ですが、T3の種目を1〜2種目足せます。フェイスプル、カール、サイドレイズ、腹筋種目などが向いています。T3は軽めの重量で、15回×3セット以上にしてください。

### GZCLPとGZCLはどう違いますか？

GZCLは、Cody Lefeverが考案したトレーニングの方法全体を指します。GZCLPは、そのGZCLの原則をリニアプログレッションで具体化した、初心者向けの個別のプログラムです（「LP」はLinear Progression、リニアプログレッションの略です）。The RipplerやJacked & Tanなどほかのプログラムは、ピリオダイゼーション（期分け）を使います。

```liftoscript
# Week 1
## Day 1
// ...t1
t1: Squat / ...t1

// ...t2
t2: Bench Press / ...t2

// ...t3
t3: Lat Pulldown / ...t3

## Day 2
// ...t1
t1: Overhead Press / ...t1 / progress: custom(increase: 5lb) { ...t1 }

// ...t2
t2: Deadlift / ...t2 / progress: custom(increase: 10lb, stage3increase: 15lb) { ...t2 }

// ...t3
t3: Bent Over Row / ...t3

## Day 3
// ...t1
t1: Bench Press / ...t1 / progress: custom(increase: 5lb) { ...t1 }

// ...t2
t2: Squat / ...t2 / progress: custom(increase: 10lb, stage3increase: 15lb) { ...t2 }

// ...t3
t3: Lat Pulldown / ...t3

## Day 4
// ...t1
t1: Deadlift / ...t1

// ...t2
t2: Overhead Press / ...t2

// ...t3
t3: Bent Over Row / ...t3


// **T1**. It starts with **85% of 5RM** (or approximately **75% or 1RM**).
// You can adjust your 1RM by clicking the **1RM** link under the exercise name.
// There's the RM calculator there to help find it out if you don't know it

// **T1**.

// **T1**. Retest week, you may skip warmups. Find your new 5RM (5 rep max), as follows
// * Start with the bar, do 5 reps.
// * Throw on some more weight, do 5 reps.
// * Repeat, when the bar starts to get heavy, make smaller jumps.
// * When you finally get to a set that is hard, but you do it - take that number, and enter into "5RM Test" set weight
// * Mark it completed!
t1 / used: none / 4x3, 1x3+ / 5x2, 1x2+ / 9x1, 1x1+ / 1x5 (5RM Test) / 75% / progress: custom(increase: 10lb) {~
  if (descriptionIndex == 1) {
    descriptionIndex = 2
  }
  if (setVariationIndex == 4) {
    descriptionIndex = 2
    setVariationIndex = 1
    weights = completedWeights[1] * 0.85
    rm1 = completedWeights[1] / rpeMultiplier(5, 10)
  } else if (completedReps >= reps) {
    weights = completedWeights[ns] + state.increase
  } else if (setVariationIndex == 3) {
    descriptionIndex = 3
    setVariationIndex += 1
  } else {
    setVariationIndex += 1
  }
~}

// **T2**. Start with **35% of 1RM**.
// You can adjust your 1RM by clicking the **edit** icon, and setting the **1 Rep Max** value.
// There's the RM calculator there to help find it out if you don't know it

// **T2**.
t2 / used: none / 3x10 / 3x8 / 3x6 / 62% / progress: custom(stage1weight: 0lb, increase: 5lb, stage3increase: 10lb) {~
  if (descriptionIndex == 1) {
    descriptionIndex = 2
  }
  if (completedReps >= reps) {
    weights = completedWeights[ns] + state.increase
  } else if (setVariationIndex == 1) {
    state.stage1weight = completedWeights[ns]
    setVariationIndex += 1
  } else if (setVariationIndex == 2) {
    setVariationIndex += 1
  } else {
    setVariationIndex = 1
    weights = state.stage1weight + state.stage3increase
  }
~}

// **T3**.
t3 / used: none / 2x15, 1x15+ / 60% 90s / progress: custom(increase: 5lb) {~
  if (completedReps[ns] >= 25) {
    weights = completedWeights[ns] + state.increase
  }
~}
```
