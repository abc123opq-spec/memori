r/Fitnessのwikiが定番として勧める、最初のプログラムです。週3日、2つのワークアウトを交互に行い、バーベル種目は6つです。セットの組み方はどの種目も同じで、ストレートセット2セットのあと、全力のAMRAP（限界までのレップ数）を1セット行います。毎回重量を足し、停滞したら10%ディロードして、3か月で次のプログラムに移ります。

## 成り立ちと考え方

ベーシックビギナールーティン（Basic Beginner Routine、BBR）は、インターネット最大級のフィットネスコミュニティのひとつ、[r/Fitnessのwiki](https://thefitness.wiki/routines/r-fitness-basic-beginner-routine/)が、初心者に最も勧めているプログラムです。

設計の考え方は「最小有効量」です。主要な動作パターンをすべてカバーできる最少の種目に絞り、シンプルなリニアな重量アップで毎回伸ばし、難しく考えずにジムに通う習慣をつくります。あえて必要最小限にしてあるので、初心者はプログラムの管理に気を取られず、フォームの習得に集中できます。

## 向いている人

- **経験**：まったくの初心者、または長いブランクのあとに戻るリフター
- **目的**：バーベル種目を覚え、基礎的な筋力をつけ、トレーニングの習慣をつくること
- **食事は問わない**：初心者なら、摂取カロリーが不足していても筋力は伸びます

## メリットとデメリット

**メリット**

- 1回のワークアウトで行う種目は3つだけなので、30〜45分で終わります。
- 最後のAMRAPセットが強度を自動で調整してくれます。バーの重量以外にも、進歩を測れる指標になります。
- 主要な動作パターンを、2週間に3回ずつ鍛えます。フォームを練習する機会がたっぷりあります。
- 加速するプログレッション（AMRAPで10回を超えたら増量幅が2倍）のおかげで、序盤の数週間が単調になりません。

**デメリット**

- 腕、肩、体幹の直接的なアイソレーション種目がありません。必要なら自分で足してください。
- ワークセットは1回のワークアウトで9セットだけです。2〜3か月でこのボリュームでは足りなくなります。
- 上半身は、原文では1.25kgずつ増やします。このアプリのkg表記では2.5kgずつにそろえているので、その分ディロードの回数は増えます。1.25kgずつ進めるには、片側0.625kg相当のマイクロプレートが必要です。
- 補助種目は組まれていません。ベースのプログラムは、本当に1日3種目だけです。

## プログラムの構成

- **スプリット**：全身。AとBの交互
- **頻度**：週3日。セッションの間には最低1日の休みを入れます
- **ローテーション**：1週目はA/B/A、2週目はB/A/B、以降は繰り返し
- **1回の時間**：30〜45分
- **期間**：最長3か月。その後は、より大きなプログラムに移ります

月・水・金で行う場合の典型的な1週間：

| 月曜 | 水曜 | 金曜 |
|--------|-----------|--------|
| ワークアウトA | ワークアウトB | ワークアウトA |

翌週は逆になり、B/A/Bです。

## 種目の選び方と理由

どのワークアウトも、プル、プッシュ、下半身のコンパウンドを1つずつ行います。毎回、主要な筋群をすべて鍛えられます。

**ワークアウトA**：[{Bent Over Row}]（水平プル）→ [{Bench Press}]（水平プッシュ）→ [{Squat}]（大腿四頭筋が主体の下半身）。ベンチの前にロウを行うと、上背部のウォームアップになり、ベンチプレスのポジションが安定しやすくなります。

**ワークアウトB**：[{Chin Up}]（垂直プル）→ [{Overhead Press}]（垂直プッシュ）→ [{Deadlift}]（ヒップが主体の下半身）。ワークアウトAと組み合わせることで、水平・垂直それぞれのプッシュとプルの4パターンと、スクワットとヒンジの両方の動作を、毎週鍛えられます。

**代替**：自重のチンアップがまだできない場合は、[{Chin Up}]を[{Lat Pulldown}]か、バンドで補助したチンアップに替えてください。それ以外の入れ替えは勧めません。この6種目を身につけることが目的だからです。

## セット数とレップ数

どの種目も **2×5、1×5+**（5回を2セット、AMRAPを1セット）です。

最初の2セットは、指定の重量でボリュームを稼ぎます。3セット目が勝負です。フォームを保ったまま、できるだけ多くの回数を行います。RPE 8〜9（あと1〜2回できる状態）で止めてください。完全な限界まで粘る必要はありません。

AMRAPセットは2つの役割を持ちます。進歩の指標（各重量で何回できたかを時間をかけて記録する）であり、加速するプログレッションのルールを動かす条件でもあります。

## プログレッシブオーバーロード

**成功**（指定のレップ数をすべて完了）：

| 種目の種類 | 1回あたりの増量 |
|-----------|---------------------|
| 上半身（[{Bench Press}]、[{Overhead Press}]、[{Bent Over Row}]、[{Chin Up}]） | +2.5kg（kg 表記では 2.5kg にそろえています） |
| 下半身（[{Squat}]、[{Deadlift}]） | +2.5kg |

AMRAPセットで **10回を超えた** 場合は、増量幅が2倍になります（上半身も下半身も+5kg。kg 表記では上半身の増量も 2.5kg にそろえています）。

**失敗**（すべてのレップを完了できなかった）：次のワークアウトで重量を **10%** 下げます。軽くした重量でAMRAPの自己ベストを狙ってください。ディロードを、後退ではなくチャンスに変えます。

各種目は独立して管理します。[{Bench Press}]が停滞しても、[{Squat}]には影響しません。

## どのくらい続けるか、次は何か

**最長3か月です。** このプログラムは意図的にボリュームを低くしてあります。目的地ではなく、発射台です。

**切り替えどき**：複数の種目で、ディロードが頻繁に起きる。AMRAPセットが5回ぎりぎりしか届かない。8〜12週間続けて、より多いボリュームや種目の種類が欲しくなった。

**次によいプログラム**：
- [GZCLP](/programs/gzclp)：ボリュームが増え、ティア構造の種目構成になります。プログレッションは引き続きリニアです
- [5/3/1 for Beginners](/programs/the5314b)：ピリオダイゼーションがあり、補助種目のテンプレートも組み込まれています
- [r/Fitnessの推奨ルーティンのページ](https://thefitness.wiki/routines/)にあるもの

## 必要な器具

- バーベル、プレート、スクワットラック、フラットベンチ
- **マイクロプレート**（片側0.625kg相当）：原文の1.25kgずつの増量用。このアプリでは2.5kgずつにそろえているので、なくても進められます

[{Chin Up}]ができない場合は、バンドを使う懸垂バーか、[{Lat Pulldown}]のマシンが代わりになります。

## 休憩時間

- **セット間**：2分。高重量のセットでは、必要なら3分まで延ばします。
- **種目間**：3〜5分。

## 開始重量の決め方

初日の各種目で、次の手順を行います。

1. 空のバー（20kg）で5回行う
2. 5〜10kg足して、さらに5回行う
3. フォームが崩れる、またはバーのスピードが落ちるまで繰り返す
4. その重量を開始重量にする

**思っているより軽く始めてください。** リニアプログレッションで、すぐにきつい重量になります。最初から重すぎると、序盤で停滞します。

[{Chin Up}]：自重（追加重量0kg）から始めます。全セットをこなせるようになったら、ディップベルトで重量を足します。

## よくあるアレンジ

- **補助種目を足す**：メイン種目のあとに、プッシュ、プル、体幹の種目を各2〜3セット行います。おすすめは[{Face Pull}]、[{Bicep Curl}]、[{Hanging Leg Raise}]、[{Triceps Pushdown}]です。軽めの重量で、10〜15回にしてください。
- **バックオフセット**：ワークセットのあとに重量を20〜30%下げて、5〜8回を1〜3セット追加します。ボリュームとフォームの練習が増やせます。
- **チンアップができない場合**：自重で回数をこなせる筋力がつくまでは、[{Lat Pulldown}]を8〜12回×3セットで行います。

### ベーシックビギナールーティンは、まったくの初心者に向いていますか？

はい。r/Fitnessのwikiが、トレーニング経験のない人に最初に勧めているプログラムです。基本のバーベル動作6つのなかから、1回あたり3種目だけに絞っています。圧倒されることなく、正しいフォームを身につけられます。

### ベーシックビギナールーティンは週何日ですか？

週3日のプログラムで、セッションの間には最低1日の休みを入れます。月・水・金が一般的なスケジュールです。AとBの2つのワークアウトが毎週入れ替わり、1週目はA/B/A、2週目はB/A/Bです。

### ベーシックビギナールーティンは、どのくらい続けるのがよいですか？

最長3か月です。このプログラムはあえてボリュームを低くして、種目を覚え、ジムに通う習慣をつくることを狙っています。8〜12週間たったら、GZCLPや5/3/1 for Beginnersのように、ボリュームが多いプログラムに移ってください。

### ベーシックビギナールーティンで停滞したらどうしますか？

ある種目で指定のレップ数をすべて完了できなかったら、次のワークアウトでその種目の重量を10%下げます。軽くした重量で、AMRAPの自己ベストを狙ってください。種目ごとに独立して管理しているので、1つの種目が停滞しても、ほかの種目には影響しません。

### ベーシックビギナールーティンに補助種目を足せますか？

はい。メインの3種目のあとに、プッシュ、プル、体幹の種目を各2〜3セット、10〜15回で加えます。フェイスプル、アームカール、ハンギングレッグレイズ、トライセップスプッシュダウンがおすすめです。軽めの重量にして、補助種目がメイン種目の邪魔にならないようにしてください。

### ベーシックビギナールーティンでチンアップができない場合はどうしますか？

チンアップをラットプルダウンの8〜12回×3セットに替えるか、バンドで補助したチンアップを使います。自重のチンアップができる筋力がつくまで続けて、そのあとは、プログラムどおりの種目に切り替えます。

```liftoscript
# Week 1
## Workout A
main / used: none / 2x5, 1x5+ \
  / progress: custom(increase: 2.5lb) {~
  if (completedReps >= reps) {
    for (var.i in completedReps) {
      if (completedReps[ns] > 10) {
        weights[var.i] = completedWeights[var.i] + state.increase * 2
      } else {
        weights[var.i] = completedWeights[var.i] + state.increase
      }
    }
  } else {
    weights *= 0.9
  }
~}

Bent Over Row / ...main / 95lb
Bench Press / ...main / 45lb
Squat / ...main / 45lb / progress: custom(increase: 5lb) { ...main }

## Workout B
Chin Up / ...main / 0lb
Overhead Press / ...main / 45lb
Deadlift / ...main / 95lb / progress: custom(increase: 5lb) { ...main }
```
