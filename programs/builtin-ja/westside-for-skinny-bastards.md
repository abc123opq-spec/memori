Joe DeFrancoが、Westside Barbellのコンジュゲートメソッドを、アスリートや痩せ型のリフター向けに作り替えた週4日のプログラムです。上半身の日が2日あり、1日は重く（マックスエフォート）、もう1日は高レップ（リピティション法）です。ほかに、ジャンプとモビリティの日と、重い下半身の日があります。マックスエフォートの種目は、6週間のサイクルで2週間ごとに替わります。上半身はBench Press → Incline Bench Press → Bench Press Close Grip、下半身はBox Squat → Deadlift → Squatの順です。真の1RMではなく、重い3〜5回の最大重量を軸にするので、競技のパワーリフターでない人にとって、より安全で現実的です。

## 成り立ちと考え方

Westside for Skinny Bastards（WS4SB）は、ニュージャージー州の筋力トレーニングのコーチ、[Joe DeFranco](https://www.defrancostraining.com/westside-for-skinny-bastards-part3/)が作りました。プロのアスリートから、ふつうにジムに通う人まで指導してきた人物です。最初の版は2005年ごろ、Part 2は2007年、決定版のPart 3は2009年に公開されました。

DeFrancoは、ギアありのパワーリフター向けだったLouie Simmonsの[Westsideコンジュゲートメソッド](/programs/westside-conjugate-method)を、「skinny bastard（痩せ型）」層向けに作り直しました。筋量が足りず、従来のWestsideの重量やボリュームをこなせないアスリートやトレーニーのためです。主な変更点は3つあります。1RMではなく3〜5回の最大重量を使うこと、ダイナミックエフォートの日はスピードスクワットではなくジャンプトレーニングにすること、そして、競技の練習と回復に余裕を残すために、重い下半身の日を週1回だけにすることです。

考え方は明快です。数種目の重いコンパウンド種目で強くなり、ジャンプで爆発的なパワーをつけ、高レップの補助種目で筋肉をつけます。マックスエフォートの種目は2週間ごとにローテーションして、マンネリと神経系の燃え尽きを防ぎます。これはWestsideの大原則です。マックスエフォートは毎週行いますが、種目が替わるので、1つの動作に疲労がたまりすぎません。

## 向いている人

- **経験**：初心者の後半から中級者（バーベルトレーニングを継続して6か月以上）。[{Bench Press}]、[{Squat}]、[{Deadlift}]、[{Bent Over Row}]のフォームに慣れている必要があります。
- **主な目的**：筋力と筋量の両方を伸ばすこと。ジャンプトレーニングで、運動能力の面も鍛えます。
- **向いている時期**：増量期か維持期。オフシーズンのアスリート。厳格なリニアプログレッションよりバリエーションがほしく、かといって「何となく行う」よりは構造がほしいリフターです。
- **向かない人**：まったくの初心者（先に[GZCLP](/programs/gzclp)か[Basic Beginner](/programs/basicBeginner)を行ってください）、競技に向けたピーキングが必要な上級のパワーリフターです。

## メリットとデメリット

**メリット**

- 上半身の2日とも、押す種目と引く種目のボリュームのバランスがとれています。どちらの日も水平方向と垂直方向に引くので、ベンチプレス中心のプログラムで起こりがちな肩のアンバランスを防げます。
- 下半身の2日とも、片脚の種目（[{Bulgarian Split Squat}]、[{Reverse Lunge}]）が入っています。両脚のスクワットだけでは見落としがちな、左右差に対処できます。
- ダイナミックエフォートの日にジャンプトレーニングを使うので、2回目のスクワットの日のような、重い軸への負荷や筋肉痛を避けながら、爆発的なパワーと運動能力をつけられます。
- マックスエフォートは、1RMではなく3〜5回の最大重量を使います。コーチのいない人にも安全で、負荷を受ける時間が長いぶん、筋肉もつきやすくなります。
- 2週間ごとの種目ローテーションが組み込まれているので、神経系の燃え尽きを防ぎ、飽きずに続けられます。6週間のサイクルで、3つのMEバリエーションをこなします。

**デメリット**

- マックスエフォートの種目はワークセットが1セットだけなので、[5/3/1](/programs/the5314b)や[PHUL](/programs/phul)のようなプログラムよりも、重いボリュームは少なくなります。そのかわり、1セットあたりの強度は高くなります。
- メイン種目のプログレッションはオートレギュレーションです。重量を足すタイミングは、固定のルールではなく自分で決めます。DeFrancoの元の指示どおりですが、%で決まるプログラムよりも、自分を把握している必要があります。
- ダイナミックエフォートの日は、週に2回重いスクワットをしたいリフターには、軽すぎると感じるかもしれません。
- ふくらはぎの直接的な種目はありません。ふくらはぎを優先したい場合は、自分で足してください。

## プログラムの構成

- **スプリット**：上半身と下半身を組み合わせた型です。上半身は2種類（マックスエフォートとリピティション）、下半身も2種類（ダイナミックエフォートとマックスエフォート）あります。
- **ピリオダイゼーション**：6週間サイクルのコンジュゲート方式です。マックスエフォートの種目は2週間ごとに替わり、補助種目はずっと同じです。
- **スケジュール**：週ごとに固定で、月・火・木・金に行います。水曜と週末は休みです。
- **1週間の流れ**：マックスエフォートの上半身 → ダイナミックエフォートの下半身 → 休み → リピティションの上半身 → マックスエフォートの下半身 → 休み → 休み（プログラム内の日の名前はMax-Effort Upper Body、Dynamic-Effort Lower Body、Repetition Upper Body、Max-Effort Lower Bodyです）
- **ローテーション**：1〜2週目のME種目は[{Bench Press}]と[{Box Squat}]です。3〜4週目は[{Incline Bench Press}]と[{Deadlift}]に替わります。5〜6週目は[{Bench Press Close Grip}]と[{Squat}]に替わります。6週目が終わったら、最初に戻ります。

## 種目の選び方と理由

**マックスエフォートの上半身**は、ローテーションするME種目から始めます。その週でいちばん重い押す種目です。1〜2週目の[{Bench Press}]は、水平方向に押す基本の種目です。3〜4週目の[{Incline Bench Press}]は、角度を変えて、胸の上部と三角筋の前部に重点を移します。5〜6週目の[{Bench Press Close Grip}]は、すべてのプレス動作でロックアウトを担う、上腕三頭筋に負荷をかけます。このローテーションで、6週間のサイクルのあいだに、同じ動作パターンを3つの角度から鍛えます。

続いて、補強種目として[{Incline Bench Press, Dumbbell}]を高レップで2セット行い、プレスで使う筋肉に血液を流し込みます。[{Bent Over Row}]と[{Face Pull}]はスーパーセットにして、水平方向に引く動作と、三角筋の後部を鍛えます。DeFrancoが重視する、押す・引くのバランスです。[{Shrug}]は僧帽筋の上部を直接鍛え、最後に[{Bicep Curl, Barbell}]でひじを曲げる筋肉を鍛えて終えます。

**ダイナミックエフォートの下半身**は、従来のWestsideのスピードスクワットを、[{Jump Squat, Bodyweight}]に置き換えています。DeFrancoは、痩せ型のリフターは重いスクワットを週に2回行うと回復できない、と考えました。ジャンプなら、強い筋肉痛を起こさずにパワーを伸ばせます。[{Bulgarian Split Squat}]は、片脚で可動域を大きくとる種目です。[{Romanian Deadlift}]は、股関節を折り曲げる動きで、体の後面を鍛えます。[{Cable Crunch}]は、重量をつけた腹筋の種目です。この日は、意図的にボリュームを少なくしてあります。ここで筋肉痛になると、週の後半のマックスエフォートの下半身の日に響くからです。

**リピティションの上半身**では、[{Bench Press, Dumbbell}]を高レップで3セット行います。リピティション法は、中程度の重量でボリュームと代謝ストレスをかけ、筋肉を大きくする方法です。[{Lat Pulldown}]と[{Reverse Fly}]はスーパーセットにして、垂直方向に引く動作と三角筋の後部を鍛えます。1日目の水平方向に引く動作を補います。[{Lateral Raise}]は三角筋の中部を直接鍛えます。[{Shrug, Barbell}]と[{Hammer Curl}]は、スーパーセットにして、僧帽筋と腕を鍛えます。

**マックスエフォートの下半身**では、ローテーションするME種目を行います。1〜2週目の[{Box Squat}]は、Westsideを代表する種目です。腰を後ろに引き、股関節から折り曲げて、静止した状態から力を出す動作を身につけます。3〜4週目の[{Deadlift}]は、最も重い重量で、体の後面全体を鍛えます。5〜6週目の[{Squat}]は、運動能力と全般的な筋力にもっとも直接つながります。[{Reverse Lunge}]は片脚の種目、[{Back Extension}]は体の後面の強化、[{V Up}]は自重の腹筋で、最後を締めます。

## セットとレップの組み方

- **マックスエフォートの種目**（[{Bench Press}]、[{Box Squat}]と、そのローテーション種目）：ウォームアップで段階的に重くしてから、3〜5回のトップセットを1セット行います。本当の最大努力で、ぎりぎりやり切れる重量を選びます。軽い重量から重い重量へのウォームアップセットは、自動で作られます。
- **補強種目**（[{Incline Bench Press, Dumbbell}]）：同じ重量で、15〜20回×2セットです。1セット目で15〜20回できる重量を選びます。セット間の休憩は3分です。
- **リピティション種目**（[{Bench Press, Dumbbell}]）：15〜20回×3セットです。最初の2セットは、あと1〜2回の余力を残し、3セット目は全力で行います。
- **引く種目のスーパーセット**（[{Bent Over Row}]＋[{Face Pull}]、[{Lat Pulldown}]＋[{Reverse Fly}]）：それぞれ8〜12回×3セットを、スーパーセットで行います。
- **補助種目**（シュラッグ、カール、ランジ、バックエクステンション）：種目に応じて、6〜15回×3〜4セットです。
- **ジャンプトレーニング**：3回×5セットです。疲れさせることではなく、最大の高さと爆発力に集中します。
- **腹筋**：10〜15回×3〜4セットです。

## プログレッシブオーバーロード

DeFrancoの元のプログラムは、2つの原則でできています。**メイン種目で前回を超えること**と、神経系が燃え尽きる前に、**2〜3週間ごとに種目をローテーションすること**です。DeFrancoはこう述べています。「3回の最大重量を狙っても、5回の最大重量を狙っても、目標は毎週、自己ベストを更新することだ」

**マックスエフォートの種目**（[{Bench Press}]、[{Box Squat}]と、そのローテーション種目）：3〜5回のレップ範囲で示されます。ウォームアップを重ねて、その範囲のトップセットを行います。実際のレップと重量はアプリに記録され、次のワークアウトの開始点として表示されます。それを超えるのが目標です。同じ重量でレップを増やすか、レップが減っても重量を増やします。

表示の変わり方は次のとおりです。`1x3-5 / 60kg` から始めます。3回できたら、目標は変わらず `1x3-5 / 60kg` のままです。4回できたら、目標は `1x4-5 / 60kg` になります（下限が上がります）。5回できたら、目標は `1x5 / 60kg` になります（範囲が1つのレップ数に絞られ、この重量では上限に達したことを示します）。そこで2つの選択肢があります。(a) 次のワークアウトで5回を超えると、プログラムが自動で2.5kgを足し、`1x3-5 / 62.5kg` に戻します。(b) 手動で65kgに上げると、そのときのレップ数が、新しい `1x3-5 / 65kg` の範囲の下限になります。これがオートレギュレーションのプログレッションです。重量を足すタイミングは、その日の調子に合わせて自分で決め、プログラムは自己ベストを記録します。

プログラムが新しいME種目にローテーションしたときは、その種目をゼロから始めます。4週間後にその種目に戻ってきたときは、前回の続きから始めます。

**補強種目**（[{Incline Bench Press, Dumbbell}]）と**リピティションの日のメイン種目**（[{Bench Press, Dumbbell}]）：**ダブルプログレッション**を使います。15〜20回の範囲で行い、すべてのセットで20回に届いたら、2.5kg足して15回に戻します。DeFrancoの「レップで上回り、そのあと重量を足す」という考え方を単純にして、複数のセットでも管理しやすくしたものです。

**補助種目**（ロウ、カール、シュラッグ、ランジなど）：DeFrancoは、これらに正式なプログレッションを決めておらず、レップ範囲だけを示しています。この版では、現実的な初期設定としてダブルプログレッションを使います。すべてのセットで範囲の上限に届いたら、2.5kg足して、下限に戻します。

**ジャンプトレーニング**には、重量のプログレッションはありません。ジャンプの質に集中します。最大の高さ、きれいな着地、完全な伸び上がりです。

**停滞したとき**：2週間ごとの種目ローテーションが、ほとんどの停滞を自動で解消します。[{Bench Press}]で行き詰まっても、そのあとの4週間は[{Incline Bench Press}]と[{Bench Press Close Grip}]を行います。違う角度から筋力をつけると、停滞を抜けられることが多くあります。DeFrancoの助言は次のとおりです。「数週間おきに、指標になる種目で自分を試すこと。伸びていればプログラムは機能している。そうでなければ、種目の選び方、トレーニングのボリューム、食事を見直すこと」

## 続ける期間と次のプログラム

進歩しているかぎり、WS4SBはいつまでも続けられます。DeFrancoは、短いサイクルのプログラムではなく、長期のトレーニングシステムとして設計しました。6週間のサイクルを繰り返し、ローテーションが回るたびに、前にその種目を行ったときより強くなっているはずです。オフシーズンを通して、6〜12か月以上続けるアスリートも多くいます。

**調整を考えるタイミング**：6週間のサイクルを何周もして、すべてのME種目のローテーションで記録が頭打ちになったとき。睡眠も栄養も足りているのに、ワークアウトが苦行に感じるときです。

**次のプログラム**：%でプログレッションを組みたいなら[5/3/1](/programs/the5314b)、構造化されたピリオダイゼーションなら[The Rippler](/programs/gzcl-the-rippler)、本物の1RMのトレーニングに進む準備ができたなら、完全版の[Westsideコンジュゲートメソッド](/programs/westside-conjugate-method)があります。ボリュームをもっと増やしたいなら、[PHAT](/programs/phat)を試してください。

## 必要な器具

バーベル、ダンベル、ケーブルマシン、ボックススクワット用のボックス（ベンチかプライオボックスで代用できます）が必要です。

**自宅ジムでの代用**：
- [{Lat Pulldown}] → [{Chin Up}]または[{Pull Up}]
- [{Cable Crunch}] → [{Hanging Leg Raise}]、または重量をつけた[{Sit Up}]
- [{Face Pull}] → ダンベルで行う[{Reverse Fly}]
- [{Back Extension}] → [{Good Morning}]

## 休憩時間

- **マックスエフォートの種目**：3分。トップセットのために、完全に回復させることが重要です。
- **補強種目**：セット間で3分
- **スーパーセットの補助種目**（ロウ＋フェイスプル、プルダウン＋リバースフライ、シュラッグ＋カール）：スーパーセットのあいだに90秒
- **アイソレーション種目とそのほかの補助種目**：60秒
- **リピティションの日のメイン種目**：2分
- **ジャンプトレーニング**：90秒。爆発力を保つために、完全に回復させます。
- **腹筋**：60秒

## 開始重量の決め方

**マックスエフォートの種目**（[{Bench Press}]、[{Box Squat}]、[{Incline Bench Press}]、[{Deadlift}]、[{Bench Press Close Grip}]、[{Squat}]）：しっかりした5回ができる重量、つまり種目ごとの5RMの目安から始めます。3回から5回へのダブルプログレッションで、自然と適切な強度になります。5RMがわからなければ、推定1RMの約80%を使います。

**補助種目**：軽く始めます。指定のセットすべてを、あと2〜3回の余力を残して完了できる重量を選びます。ダブルプログレッションで、2〜3週間のうちに、きつい重量に近づきます。

**よくある間違い**：[{Box Squat}]を初めて行うのに、重すぎる重量から始めることです。腰を後ろに引いて爆発的に立ち上がる技術は、ふつうのスクワットとは違います。動きを覚えるまでは、ふだんのスクワットから20〜30%軽くしてください。

## よくあるアレンジ

- **3日版**（「Washed-Up Meathead」テンプレート）：月曜にマックスエフォートの上半身、水曜にマックスエフォートの下半身、金曜にリピティションの上半身を行います。ダイナミックエフォートの日はなくします。35歳を超えたリフターや、回復力に限りがある人に向いています。
- **コンディショニングを足す**：DeFrancoは、休みの日に週2〜3回、ソリ引き、プラウラープッシュ、坂道ダッシュを行うよう勧めています。コンディショニングは、ワークアウトとは別に行ってください。
- **MEの種目に5/3/1を使う**：DeFranco自身も、マックスエフォートの種目に[5/3/1](/programs/the5314b)の%を使うことがあります。「最大まで重量を上げる」方法を、%で決める構造化された負荷に置き換えます。
- **ローテーションのカスタマイズ**：組み込みのローテーションは、上半身が[{Bench Press}] → [{Incline Bench Press}] → [{Bench Press Close Grip}]、下半身が[{Box Squat}] → [{Deadlift}] → [{Squat}]です。プログラムを編集すれば、これらを[{Overhead Press}]、[{Trap Bar Deadlift}]、[{Front Squat}]などの別のバリエーションに替えられます。
- **三角筋の後部の種目を足す**：肩の健康が気になるなら、上半身の日の最後に、[{Face Pull}]か[{Reverse Fly}]を1セット追加してください。

<!-- faq -->

### Westside for Skinny Bastardsは初心者に向いていますか？

WS4SBは、バーベルトレーニングを継続して少なくとも6か月になるリフターに最適です。このプログラムを始める前に、ベンチプレス、スクワット、ロウでしっかりしたフォームが必要です。まったくの初心者は、GZCLPやBasic Beginnerのような、もっと単純なリニアプログレッションのプログラムから始めてください。

### Westside for Skinny Bastardsは週に何日ですか？

WS4SB IIIは週4日のプログラムです。マックスエフォートの上半身（月曜）、ダイナミックエフォートの下半身（火曜）、リピティションの上半身（木曜）、マックスエフォートの下半身（金曜）です。回復の時間がもっと必要なリフターのために、DeFrancoは週3日の「Washed-Up Meathead」版も公開しています。

### WS4SBと完全版のWestsideコンジュゲートメソッドは何が違いますか？

WS4SBは、1RMではなく3〜5回の最大重量を使い、スピードスクワットをジャンプトレーニングに置き換え、重い下半身の日は週1回です。完全版のWestsideは、1〜3回の最大重量、バンドとチェーンを使ったバーベルのスピードワーク、週2回の重い下半身の日です。WS4SBはアスリートと一般のリフター向けで、完全版のWestsideは上級のパワーリフター向けです。

### WS4SBの種目のローテーションは、どう進みますか？

マックスエフォートの種目は、6週間のサイクルのなかで、2週間ごとに自動で替わります。上半身は、Bench Press、Incline Bench Press、ナローグリップベンチプレスの順です。下半身は、Box Squat、Deadlift、Squatの順です。補助種目はずっと同じです。6週間たつと、最初に戻ります。

### 減量中にWS4SBを行えますか？

行えますが、回復は難しくなります。週3日版に切り替えて、補助種目のボリュームを1種目あたり1セット減らすことを検討してください。カロリー不足の期間は、筋肉と筋力を保つために、マックスエフォートのセットは重いままにします。

### ボックススクワット用のボックスがないときは？

プログラムは、6週間のサイクルのなかで、Box SquatをDeadliftとSquatとローテーションします。そのため、ボックスが必要なのは6週間のうち2週間だけです。ボックスがまったくない場合は、その2週間は、プログラムを編集して、Front SquatかTrap Bar Deadliftに替えてください。

### WS4SBは、1回のワークアウトに何分かかりますか？

ほとんどのワークアウトは60〜75分です。マックスエフォートの上半身は、ウォームアップで段階的に重くすることと、補助種目の数が多いので、いちばん長くなりがちです。ダイナミックエフォートの下半身は、ジャンプトレーニングが短時間で終わり、補助種目のボリュームも意図的に少ないので、いちばん短くなります。

/// Autoregulated progression template. Raises minReps when you beat your rep PR at the same weight.
/// If you blow past maxTarget, auto-adds weight. If you manually increase weight, resets the range.
autoreg / used: none / 1x1 / progress: custom(minTarget: 3, maxTarget: 5, increment: 5lb) {~
  for (var.i in completedWeights) {
    if (completedReps[var.i] > 0) {
      if (completedWeights[var.i] > weights[var.i]) {
        weights[var.i] = completedWeights[var.i]
        minReps[var.i] = state.minTarget
        reps[var.i] = state.maxTarget
      } else if (completedWeights[var.i] == weights[var.i]) {
        if (completedReps[var.i] > state.maxTarget) {
          weights[var.i] = weights[var.i] + state.increment
          minReps[var.i] = state.minTarget
          reps[var.i] = state.maxTarget
        } else if (completedReps[var.i] > minReps[var.i]) {
          minReps[var.i] = completedReps[var.i]
        }
      }
    }
  }
~}
