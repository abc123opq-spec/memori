Jim Wendlerの5/3/1メソッドを初心者向けに応用した、週3日の全身プログラムです。毎回、2つのメインのバーベル種目を5/3/1のレップスキームで行い、さらに5×5のFSL（First Set Last）の補強ボリュームを加えます。そのあとに、プッシュ・プル・体幹の補助種目を、カテゴリごとに50〜100回行います。

<!-- more -->

## 成り立ちと考え方

初心者向け5/3/1は、Jim Wendlerが自身の[5/3/1システム](https://www.jimwendler.com/blogs/jimwendler-com/101065094-5-3-1-for-a-beginner)を、初心者向けに応用したものです。Wendlerは、Westside Barbellの元トレーニーで、約454kgのスクワットを挙げた人物です。5/3/1は「軽く始めて、ゆっくり伸ばす」という一つの原則を軸に作られました。標準の5/3/1は、1日にメイン種目を1つ、4日で行います。初心者向けのバージョンでは、それを1日2種目の全身3日にまとめ、シンプルさを保ちながら、大きなバーベル種目を行う機会を週内で増やしています。

このシステムの中心は、トレーニングマックス（TM）の考え方です。ワークの重量はすべて、本当の最大ではなく、実際の1RMの90%を基準にします。余裕を持たせることで、レップを粘る場面がなくなります。どのセットも、速く、コントロールして、よいフォームで行います。重量が上がるのは、3週間のサイクルごとに2.5〜5kgだけです。最初は遅く感じますが、数か月かけて、大きな筋力になります。

## 向いている人

- **経験**：初心者から中級者（ジム経験3〜18か月）。始める前に、[{Squat}]、[{Bench Press}]、[{Deadlift}]、[{Overhead Press}]のフォームに慣れていること。
- **主な目的**：筋力です。FSLのボリュームと補助種目で、筋肉も多少つきます。
- **特に合う場面**：増量期か維持期です。減量中でも行えますが、回復がきついときは、補助種目のボリュームをカテゴリごとに25〜50回に減らしてください。

## メリットとデメリット

**メリット**

- [{Squat}]と[{Bench Press}]を週2回（1日目と3日目）行うので、初心者がいちばん苦労するこの2種目のフォームが早く身につきます
- トレーニングマックスのシステムなので、重すぎる負荷をかけることがありません。常にレップに余裕があり、自信がつき、ケガのリスクも下がります
- FSLの5×5で、無理のない強度（65〜75% TM）のまとまったボリュームが加わり、最大に届かない負荷でフォームを固められます
- 週3日で、1回45〜60分ほどです。ほとんどのスケジュールに収まります
- AMRAPのセットがオートレギュレーションになります。調子のよい日はレップが増え、悪い日は最低ラインで済みます

**デメリット**

- [{Deadlift}]と[{Overhead Press}]は週1回（2日目）だけなので、これらの種目を練習する頻度が限られます
- 重量の増加は固定（サイクルごとに5/5kg）で、AMRAPの結果とは関係ありません。そのため、力のある初心者は、Starting Strengthや[GZCLP](/programs/gzclp)のようなプログラムと比べて、進みが遅すぎると感じるかもしれません
- 補助種目が意図的にあいまいです（「プッシュ・プル・体幹を50〜100回」）。もっと構成がほしい初心者は、種目選びに迷うことがあります
- 3週間のサイクルに、ディロードの週が組み込まれていません。回復は自分で管理するか、6〜9週間ごとにTMテストの週を加える必要があります

## プログラムの構成

- **スプリット**：全身
- **ピリオダイゼーション**：週ごとのアンデュレーティング型（5回の週、3回の週、5/3/1の週）で、サイクルごとに固定のプログレッション
- **スケジュール**：週ごとに固定。月・水・金、または連続しない任意の3日
- **典型的な1週間**：1日目（スクワット＋ベンチプレス）/ 休み / 2日目（デッドリフト＋オーバーヘッドプレス）/ 休み / 3日目（ベンチプレス＋スクワット）/ 休み / 休み

## 種目の選び方と理由

**1日目と3日目**は、[{Squat}]と[{Bench Press}]を組み合わせます。この2種目は、頻度を上げるほど効果が出ます。初心者は、週2回練習することで、スクワットとベンチプレスのフォームが最も早く身につきます。1日目はスクワットから、3日目はベンチプレスから始めるので、それぞれの種目が1回ずつ、元気な状態で最初に行う種目になります。

**2日目**は、[{Deadlift}]と[{Overhead Press}]です。この2種目を週1回にしているのは、デッドリフトが1回あたりスクワットより疲れる（回復が追いつきにくい）ことと、オーバーヘッドプレスが、1日目と3日目のベンチプレスのボリュームの恩恵を受けられるからです。

**補助種目**は、メイン種目では足りない部分を補う、3つのカテゴリに分かれています。
- **プッシュ**（[{Push Up}]、[{Triceps Dip}]）：ベンチプレスとオーバーヘッドプレスに加えて、胸と上腕三頭筋のボリュームを増やします
- **プル**（[{Chin Up}]、[{Pull Up}]、[{Inverted Row}]）：水平方向と垂直方向のプルで、多いプレスとのバランスを取り、上腕二頭筋も鍛えます
- **片脚・体幹**（[{Hanging Leg Raise}]、[{Bulgarian Split Squat}]）：腹筋の直接的な種目と、バランスと安定性のための片脚種目です

補助種目は、自由に入れ替えられます。プッシュ、プル、片脚・体幹のどれかに当てはまる種目なら何でも構いません。目標は、特定の種目ではなく、合計のレップ数です。

## セットとレップの組み方

**メイン種目**は、3週間の5/3/1ウェーブに従います。パーセンテージはすべて、トレーニングマックス（1RMの90%）が基準です。
- **1週目（5回）**：65% TMで5回×1セット、75% TMで5回×1セット、85% TMで5回以上×1セット
- **2週目（3回）**：70% TMで3回×1セット、80% TMで3回×1セット、90% TMで3回以上×1セット
- **3週目（5/3/1）**：75% TMで5回×1セット、85% TMで3回×1セット、95% TMで1回以上×1セット

毎週の最後のセットはAMRAPです。バーのスピードとフォームを保てる範囲で、できるだけ多くのレップを行います。限界まで粘ってはいけません。バーのスピードが大きく落ちるか、フォームが崩れたら、そこで止めます。

**FSL（First Set Last）**：各メイン種目の3つのワークセットのあとに、最初のワークセットの重量に戻り、5回を5セット行います。「First Set Last」という名前は、最初のセットの重量を、最後のセットとして繰り返すことから来ています。1週目は65% TM、2週目は70% TM、3週目は75% TMの5×5になります。FSLは補強ボリュームにあたります。質のよいレップでフォームを練習できる軽さがありながら、筋力と筋肉の適応を促すだけの重さもあります。BBB（Boring But Big）やSSL（Second Set Last）のような、重めの補強ワークを使う標準の5/3/1テンプレートとの、いちばんの違いです。

**補助種目**：カテゴリ（プッシュ/プル/片脚または体幹）ごとに、合計50〜100回です。セットとレップの組み方は自由で、10回×5セット、15回×3セット、5回×10セットなど、目標のレップ数に届けば何でも構いません。

## プログレッシブオーバーロード

3週間のサイクルを終えるたびに、トレーニングマックスに重量を足します。
- **[{Squat}]と[{Deadlift}]**：＋5kg
- **[{Bench Press}]と[{Overhead Press}]**：＋2.5kg

この増量幅は固定で、AMRAPの結果によって変わりません。ゆっくり着実に進めるのが、このプログラムの設計です。

**停滞したら**：AMRAPのセットで、サイクル丸ごと、規定の最低レップ（5/3/1）に届かなかったときは、TMをサイクル3回分の増量幅だけ下げて（上半身は7.5kg、下半身は12.5kg）、組み直します。たまに調子の悪い日があるのは普通です。調整するのは、サイクル全体がきつかったときだけです。

**TMテストの週（任意のディロード）**：2〜3サイクル（6〜9週間）ごとに、テストの週を取ります。TMの重量で、3〜5回を目標に重量を上げていきます。3回以上できれば、TMは適切です。できなければ、その結果をもとにTMを計算し直します。これは、以前の「4週目ごとにディロード」という方式の代わりです。

## 続ける期間と次のプログラム

初心者向け5/3/1は、**6〜12か月**、または8〜12サイクルを終えるまで続けます。3週間ごとにTMの重量を安定して足せる限り、このプログラムは機能します。

**次へ進むサイン**：TMをリセットしてもAMRAPで3回以上できなくなった、6か月以上続けてもっと変化がほしい、筋力の目標がより専門的なプログラムを必要としている、のいずれかに当てはまるときです。

**次の選択肢**：[5/3/1 Boring But Big](/programs/the531bbb)（筋肥大のボリュームを加えます）、[5/3/1 Building the Monolith](/programs/monolith531)（とてもきつい中級者向けプログラム）、[GZCLP](/programs/gzclp)（別のプログレッションのモデルを試したい場合）。*5/3/1 Forever* にある標準の5/3/1テンプレートは、どれも自然な次のステップです。

## 必要な器具

メイン種目には、バーベル、スクワットラック、ベンチ、プレートが必要です。補助種目は、書かれている形では自重の種目を使うので、追加で必要な器具は懸垂バーだけです。

**懸垂バーがない場合**：
- [{Chin Up}] / [{Pull Up}] → [{Bent Over Row, Dumbbell}]または[{Inverted Row}]（ラックにバーベルをセットして行います）
- [{Inverted Row}] → [{Bent Over Row}]（バーベル）

**その他の補助種目の入れ替え**：
- [{Triceps Dip}] → [{Bench Dip}]または[{Skullcrusher}]
- [{Bulgarian Split Squat}] → [{Lunge}]または[{Goblet Squat}]

## 休憩時間

- **メインのワークセット**（5/3/1のセット）：**2〜3分**。必要なら、AMRAPのセットは最大5分まで。
- **FSLの5×5**：**90〜120秒**。最大ではなく、中程度に感じる強度です。
- **補助種目**：**60〜90秒**。時間を節約するため、カテゴリをまたいでスーパーセットにできます（例：チンアップのセットの間に腕立て伏せ）。

## 開始重量の決め方

1. メイン種目ごとに、スピードを保てる、きれいな3〜5回ができる重量まで上げます
2. その重量とレップ数を、1RMの計算式に入れます（例：重量×レップ数×0.0333＋重量）
3. トレーニングマックスは、**推定した1RMの90%**に設定します
4. ワークの重量はすべてTMから計算します

**よくある間違い**：トレーニングマックスに、1RMの90%ではなく、実際の1RMを使ってしまうことです。TMが高すぎると、システム全体が崩れます。スピードとボリュームを積む代わりに、レップを粘ることになります。

## よくあるアレンジ

- **コンディショニングを足す**：Wendlerは、休みの日のうち2〜3日に、軽いランニングやコンディショニングを行うことを勧めています。楽な強度にとどめ、筋トレの妨げにならないようにしてください。
- **補助種目は自由に入れ替える**：大切なのは、プッシュ・プル・片脚のカテゴリで、特定の種目ではありません。好きなように回してください。
- **補助種目を25〜50回に減らす**：ワークアウトが長引くときや、回復がきついとき（特に減量中）に行います。
- **プルのカテゴリに[{Face Pull}]を足す**：肩の健康のためです。このプログラムは、週2回のベンチプレスとオーバーヘッドプレスで、プレスの比重が高くなっています。
- **4日の5/3/1に移る**（1日1種目）：初心者向けバージョンを6か月以上続けて、1回あたりの補強ボリュームや補助種目のボリュームを増やしたくなったときです。

### 初心者向け5/3/1は、本当に初心者に向いていますか？

はい。Jim Wendlerが、自身の5/3/1システムを初心者向けに応用したものです。ジム経験が3〜18か月あり、スクワット、ベンチプレス、デッドリフト、オーバーヘッドプレスのフォームに慣れている必要があります。1回のワークアウトで2つのメイン種目を行い、自重の補助種目を組み合わせます。

### 初心者向け5/3/1は週何日ですか？

週3日のプログラムで、連続しない日（通常は月・水・金）に行います。1日目はスクワットとベンチプレス、2日目はデッドリフトとオーバーヘッドプレス、3日目はベンチプレスとスクワット（1日目と逆の順番）です。

### 初心者向け5/3/1のプログレッションはどう進みますか？

3週間のサイクルを終えるたびに、スクワットとデッドリフトのトレーニングマックスに5kg、ベンチプレスとオーバーヘッドプレスのトレーニングマックスに2.5kgを足します。この固定の増量幅は、AMRAPの結果に関係なく適用されます。ゆっくり進めるのが設計です。

### 初心者向け5/3/1のFSLとは何ですか？

FSLはFirst Set Lastの略です。3つのメインのワークセットを終えたあと、最初のワークセットの重量に戻って、5回を5セット行います。無理のない強度（トレーニングマックスの65〜75%）で補強ボリュームを積み、フォームの練習と筋力づくりに役立てます。

### 初心者向け5/3/1はどのくらい続けるのがいいですか？

6〜12か月、または8〜12サイクル続けます。3週間ごとにトレーニングマックスの重量を足せる限り、プログラムは機能します。TMをリセットしてもAMRAPのセットが最低レップにやっとの状態になったら、またはもっと変化がほしくなったら、次に進んでください。

### 5/3/1のトレーニングマックスとは何ですか？
