Jim Wendlerの5/3/1テンプレートのなかで、筋肉をつけるために最も人気のあるものです。毎回のワークアウトで、メイン種目となるバーベル種目1つに5/3/1の標準的なプログレッションを行い、同じ種目を軽めの重量で10回×5セット行います。そのあと補助種目を最小限だけ行って終わります。高レップの補強セットが筋肥大を促し、重いメインのセットが筋力を維持して伸ばします。

## 成り立ちと考え方

ボーリング・バット・ビッグ（Boring But Big、BBB）は、Jim Wendlerの[5/3/1システム](https://www.jimwendler.com/blogs/jimwendler-com/101077382-boring-but-big)に追加する補強テンプレートです。彼のブログで公開され、のちに著書 *Beyond 5/3/1* と *5/3/1 Forever* で拡張されました。Wendlerは元Westside Barbellのトレーニーで、スクワットで約454kgを挙げた人物です。5/3/1に筋肥大の要素をわかりやすく足すために、BBBを作りました。

考え方はとことん単純です。重いメインのセットのあと、同じ動作パターンを中程度の重量で高レップに追い込みます。種目選びは凝らず、補助種目の期分けもしません。バーを握って50回行うだけです。名前のとおり退屈（boring）ですが、効果があります。

## 向いている人

- **経験**：中級者（1〜3年）。毎回のワークアウトで同じ種目を合計8セット行い、フォームが崩れやすい高レップのセットも含まれるため、[{Squat}]、[{Bench Press}]、[{Deadlift}]、[{Overhead Press}]のしっかりした技術が必要です。
- **主な目的**：筋力を維持しながらの筋肥大。5/3/1のセットで筋力を保ち、5×10のセットで筋肉を大きくします。
- **向いている時期**：増量期、またはカロリーを十分にとれる維持期。5×10のセットは疲労が大きく、しっかりした回復が必要です。減量には勧められません。摂取カロリーが足りない時期は、First Set Last（FSL）のようなボリュームの少ないテンプレートを使ってください。

## メリットとデメリット

**メリット**

- 自宅ジム向きの筋肥大プログラムとして最良の部類です。メイン種目に必要なのはバーベル、スクワットラック、ベンチ、懸垂バーだけで、補助種目はダンベル1組があれば足ります。
- 進め方がきわめて単純です。メイン種目を2回（重く1回、軽く1回）行い、1回のワークアウトに補助種目を2つ足すだけです。
- 1回のワークアウトでメイン種目を50回行うため、強くしたい動作パターンそのものを鍛えて筋肉をつけられます。
- トップセットのAMRAP（限界までのレップ数）がオートレギュレーション（自己調整）の役割を果たし、トレーニングマックスが適切かどうかをすぐに確かめられます。
- 週4日で、種目をローテーションする複雑さもありません。

**デメリット**

- 5×10の[{Squat}]と[{Deadlift}]は疲労がきわめて大きく、高レップのセットの休憩を含めると、1回のワークアウトが70〜80分かかります。
- 特に下半身の日は回復への負担が大きく、十分な睡眠と、摂取カロリーが消費を上回る状態が必要です。
- 減量には向きません。ボリュームが多すぎて、カロリー不足では回復が追いつきません。

## プログラムの構成

- **スプリット**：週4日、1日にメイン種目1つ（OHP／デッドリフト／ベンチ／スクワット）
- **ピリオダイゼーション**：週ごとに変動します。5/3/1のトップセットは週ごとに変わり（5+／3+／1+）、BBBの補強ボリュームは5×10で一定です。
- **サイクル**：3週の通常週と1週のディロード週で、4週が1サイクルです。
- **スケジュール**：週ごとに固定です。月・火・木・金、または下半身の日のあいだに最低1日の休みを置ける4日が目安です。

## 種目の選び方と理由

1日ごとに、4つのメインバーベル種目のうち1つを行います。[{Overhead Press}]、[{Deadlift}]、[{Bench Press}]、[{Squat}]です。5/3/1のプログレッションに従い、BBBの補強ボリュームがつくのは、この4種目だけです。

BBBの補強セットは、メインと**同じ種目**を使います。Wendlerの考えでは、その種目が上手くなる最良の方法は、その種目をもっと行うことです。重いベンチプレスのあとに[{Bench Press}]を5×10で行うと、ウォームアップを含めて1週間にベンチプレスを80回行うことになり、大半のプログラムよりもはるかに多く練習できます。

**補助種目**は、Wendlerのプッシュ・プル・体幹のテンプレートに従い、1回のワークアウトに2種目です。毎回、引く種目または腕の種目を1つ、腕または体幹の種目を1つ組み合わせます。
- **OHPの日**：[{Chin Up}]で押す動作に対して垂直方向の引く動作を補い、[{Skullcrusher}]で上腕三頭筋のボリュームを直接足します。
- **デッドリフトの日**：上腕二頭筋に[{Bicep Curl}]（デッドリフトで背中はすでに鍛えられています）、体幹に[{Hanging Leg Raise}]。
- **ベンチの日**：スカルクラッシャーとは違う角度で上腕三頭筋を鍛える[{Triceps Extension}]と、上腕二頭筋と上腕筋を鍛える[{Hammer Curl}]。
- **スクワットの日**：背中の広がりに[{Pull Up}]、体幹の前側の安定性に[{Ab Wheel}]。

これらは、似た種目に自由に入れ替えて構いません。

## セットとレップの組み方

**メインの5/3/1** は標準的なウェーブに従います。元のプログラムでは、パーセンテージはトレーニングマックス（TM = 1RMの90%）が基準です。このMemori版では、パーセンテージを**1RMに対する%で直接**表記してあり（TMから換算済み）、1RMを設定するだけで使えます。
- **1週目（5回の週）**：5回×1セット @ 58%、5回×1セット @ 67%、5回以上×1セット @ 76%
- **2週目（3回の週）**：3回×1セット @ 63%、3回×1セット @ 72%、3回以上×1セット @ 81%
- **3週目（5/3/1の週）**：5回×1セット @ 67%、3回×1セット @ 76%、1回以上×1セット @ 85%

毎週の最後のセットはAMRAPです。バーの速さを保てる範囲で、できるだけ多くのレップを行います。バーが明らかに遅くなったり、フォームが崩れたりしたら止めます。限界まで粘る必要はありません。

**BBBの補強セット**は、1RMの50%で10回×5セットです。この重量は、最初の2セットは余裕があり、4〜5セット目はきつく感じる程度が目安です。50回をこなせないなら、重量が重すぎます。

**ディロード週**：すべてのセットを1RMの36〜54%に下げ、AMRAPは行いません。BBBのボリュームは1RMの40%に下げます。この回復週は欠かせないので、飛ばさないでください。

**補助種目**：引く種目1つと、腕または体幹の種目1つを、それぞれ10回×5セット行います。軽めから中程度の強度で行い、限界までは追い込みません。

## プログレッシブオーバーロード

3週の通常週を終えるごとに（ディロードの前に）、1RMを上げます。
- **[{Overhead Press}]と[{Bench Press}]**：+2.5kg
- **[{Squat}]と[{Deadlift}]**：+5kg

この増量幅は固定で、1RMに加えます。そのため、パーセンテージで決まる重量がすべて少しずつ上がります。ゆっくり伸ばすのは意図的です。Wendlerのルールは「軽すぎるくらいで始める」ことで、数か月かけて重量を積み上げます。

**停滞したとき**：AMRAPセットで、1サイクルのあいだ指定の最低レップ数に届かない場合（5+のセットで3〜4回しか出ない、1+のセットでそもそも失敗する、など）、重量が重すぎます。1RMを10〜15%下げて、やり直してください。

**ディロード**：4週目ごとに行います。重量を軽くし（1RMの36〜54%）、AMRAPセットは行いません。BBBのボリュームは疲労をためるので、定期的に抜く必要があります。ディロードは飛ばさないでください。

## 続ける期間と次のプログラム

BBBは**3〜6サイクル**（12〜24週）続けます。何度でも戻ってこられるテンプレートで、BBBとFSLやSSLのようなボリュームの少ないテンプレートを行き来するリフターも多くいます。

**切り替えどき**：毎回の5×10のセットが憂うつになった（精神的な燃え尽き）、睡眠も食事も足りているのに回復が悪い、筋肥大よりも最大筋力を優先したくなった、といったときです。

**次のプログラム**：**BBB 3-Month Challenge**（BBBの重量を3サイクルでTMの50%から70%へ引き上げる、より上級者向けの型）、[5/3/1 Building the Monolith](/programs/monolith531)（ボリュームがさらに多く、種目も多彩）、**5/3/1 First Set Last**（ボリュームが少なく、減量期や回復期に向く）があります。*5/3/1 Forever* にある5/3/1のテンプレートなら、どれも次のプログラムになります。

## 必要な器具

メイン種目と引く補助種目には、バーベル、スクワットラック、ベンチ、プレート、懸垂バーを使います。腕のアイソレーション種目（[{Skullcrusher}]、[{Triceps Extension}]、[{Bicep Curl}]、[{Hammer Curl}]）には、ダンベル1組かEZバーを使います。

**自宅ジムでの代用**：
- [{Skullcrusher}] → [{Bench Dip}]または[{Triceps Dip}]（自重で、器具は不要）
- [{Triceps Extension}] → [{Bench Dip}]または[{Triceps Dip}]
- [{Bicep Curl}]／[{Hammer Curl}] → [{Chin Up}]のセットを追加（ダンベルなしで上腕二頭筋を鍛えられます）
- [{Ab Wheel}] → [{Hanging Leg Raise}]または[{Plank}]
- [{Hanging Leg Raise}] → [{Ab Wheel}]または[{Flat Leg Raise}]

## 休憩時間

- **メインの5/3/1のセット**：ワークセットのあいだは**3〜5分**。AMRAPセットのあとは、BBBに入る前に長めの回復が必要かもしれません。
- **BBBの5×10のセット**：**60〜120秒**。Wendlerは、トレーニングの密度を保つために短くするよう勧めています。重量は軽めなので、それ以上は必要ありません。
- **補助種目**：**60〜90秒**。時間を節約するために、スーパーセットにしても構いません（たとえば、スカルクラッシャーのセットのあいだにチンアップを入れます）。

## 開始重量の決め方

1. メイン種目ごとに、**1RM**（最大挙上重量）を見積もるか、測定します。このMemoriのプログラムは、トレーニングマックスではなく1RMをそのまま使います。
2. ワークセットのパーセンテージは、すべてWendlerのTM基準の値から、1RM基準の値に換算済みです（TM = 1RMの90%として計算）。1RMを設定するだけで、アプリがすべて計算します。

**1RMがわからないとき**：きれいに3〜5回できる重量まで、少しずつ上げていきます。Brzyckiの式を使います。1RM = 重量 / (1.0278 - 0.0278 × レップ数)。MemoriにあるRM計算機を使っても構いません。

**よくある間違い**：1RMを高く設定しすぎることです。Wendlerの大原則は「軽すぎるくらいで始める」です。1週目（5+の日）のAMRAPセットで5回しか出ないなら、1RMはおそらく高すぎます。適切に設定できていれば、このセットは7〜8回以上出るはずです。

## よくあるアレンジ

- **BBB 3-Month Challenge**：3サイクルかけてBBBの重量を上げていきます。1か月目はTMの50%、2か月目は60%、3か月目は70%です。きつくなりますが、より大きな適応を引き出せます。このチャレンジ中、Wendlerは5/3/1の最後のセットでAMRAPを行わず、指定のレップ数だけ行うよう勧めています。
- **逆の種目でBBB**：ベンチの5/3/1のあとに[{Bench Press}]を5×10で行う代わりに、[{Overhead Press}]を5×10で行います（逆も同じ）。[{Squat}]と[{Deadlift}]も同様です。同じ動作パターンの疲労が減り、動きにも変化がつきます。この方法では、各種目が週に2回鍛えられます。
- **5s PRO**（*Forever* より）：AMRAPのセットをやめ、3週すべてで5回のストレートセットにします。中枢神経の疲労が減り、BBBの多いボリュームとの相性もよくなります。Wendlerの最近の文章で勧められています。
- **[{Face Pull}]を追加**：プレスの日に、15〜20回×3〜5セット。このプログラムはプレスが多いので、肩の健康のために入れます。

### 5/3/1 Boring But Bigは初心者に向いていますか？

BBBは中級者向けのプログラムです。1〜3年の経験と、スクワット、ベンチプレス、デッドリフト、オーバーヘッドプレスのしっかりした技術が必要です。5×10の補強セットは、疲れた状態でも良いフォームを保つことが求められます。まだ経験が浅い場合は、[5/3/1 for Beginners](/programs/the5314b)から始めてください。

### 5/3/1 Boring But Bigは週に何日ですか？

週4日のプログラムで、通常は月・火・木・金に行います。毎回、メインのバーベル種目（OHP、デッドリフト、ベンチプレス、スクワット）を1つ行い、そのあとに同じ種目を5×10で行い、補助種目を2つ行います。

### Boring But Bigは、ほかの5/3/1のテンプレートと何が違いますか？

最大の特徴は、重い5/3/1のセットのあとに、1RMの50%で5×10の補強セットを行うことです。1回のワークアウトで、メイン種目を50回上乗せできます。筋力を維持しながら筋肉をつけるうえで、最も効果的なテンプレートのひとつです。

### 5/3/1 BBBの重量はどう上げますか？

3週の通常週を終えるごとに、1RMをオーバーヘッドプレスとベンチプレスは2.5kg、スクワットとデッドリフトは5kg上げます。4週目は必ずディロードです。BBBの補強セットの重量は、ずっと1RMの50%のままです。

### 減量中に5/3/1 BBBを行えますか？

勧められません。5×10のセットは疲労が大きく、回復には十分なカロリーと睡眠が必要です。減量中は、5/3/1 First Set Last（FSL）のようなボリュームの少ないテンプレートを使ってください。

### 5/3/1 Boring But Bigはどれくらい続けますか？

3〜6サイクル（12〜24週）続けます。年間を通して、BBBとボリュームの少ないテンプレートを行き来するリフターも多くいます。毎回の5×10のセットが憂うつになったとき、回復が悪くなったとき、筋肥大よりも最大筋力を優先したくなったときが、切り替えどきです。
