推奨ルーティン（Recommended Routine、RR）は、r/bodyweightfitnessコミュニティの代表的な初心者向けプログラムです。週3回行う全身のカリステニクスで、必要な器具は懸垂バーと、ロウ（引く動作）に使えるものだけです。プレートを足していくのではなく、少しずつ難しくなる種目の段階を登っていきます。ある種目を8回×3セットできるようになったら、次の種目に進みます。プッシュ・プル・レッグの主要6種目は、時間を節約するために拮抗筋どうしの組み合わせでスーパーセットにして行い、そのあとに体幹の3種目を行います。

## 成り立ちと考え方

推奨ルーティンは、「最初はどのルーティンをやればいいか」という質問への標準的な答えとして、r/bodyweightfitnessコミュニティが作り、磨いてきたものです。現行版は2018年夏の改訂版で、種目をスーパーセットの組み合わせに整理し、プログレッションの道筋を明文化しました。体操競技のような自重の筋力トレーニングを多く取り入れています。

基本の考え方は次のとおりです。腕立て伏せに2.5kgを足すのは簡単ではないので、代わりに*てこの条件*を変えます。ルーティンの各枠は、易しい種目から難しい種目へ並べた段階表になっています。5回×3セットでできるいちばん難しい種目を選び、セッションごとに1回ずつ増やして8回×3セットまで進めたら、次の種目に上がって、また5回×3セットから始めます。ダブルプログレッションでレップを積み、種目を上げていくことで、筋力が伸びます。

詳しい解説は[r/bodyweightfitnessのwiki](https://www.reddit.com/r/bodyweightfitness/wiki/kb/recommended_routine)にあります。

## 向いている人

- **経験レベル**：まったくの初心者から、中級の入り口まで。トレーニング未経験なら、最適な入り口の1つです。
- **前提条件**：始めるための条件はありません。最初の段階（補助つきスクワット、壁腕立て、垂直ロウ）は、ほぼ誰でもできます。ロウに使うバーは必須（代用がきかない）で、できれば懸垂バーと平行棒（または代用品）もあるとよいです。
- **主な目的**：筋力と筋肥大。体重に対する筋力が身につき、たんぱく質とカロリーを十分にとれば、筋肉もはっきり増えます。
- **減量・増量・維持**：どの時期でも使えます。減量中は筋肉を維持でき、増量中は成長を後押しします。難しい段階の進みは、維持か摂取カロリー過多のときのほうが速くなります。

## メリットとデメリット

**メリット**

- 必要な器具がほとんどありません。ロウに使えるバーと懸垂バーだけでルーティン全体をカバーできるので、自宅でも公園でもできます。
- 拮抗筋のスーパーセット（懸垂とスクワット、ディップスとヒンジ、ロウと腕立て伏せ）により、片方の筋肉が働いている間にもう片方が休めるので、1回のワークアウトを45〜60分ほどに収められます。
- 段階表が難易度を自動で調整します。運動不足の初心者も、加重懸垂をこなす人も、同じルーティンで進められます。
- バーベルのプログラムでは直接鍛えにくい、体重に対する筋力と身体のコントロール（「懸垂ができるか」という種類の筋力）が身につきます。

**デメリット**

- ロウ用の水平なバーが必要です。これは代用がきかず、初心者がつまずく最大の原因は、このバーを見つけることです。
- バーベルのプログラムより管理する項目が多くなります。保持時間で進む段階もあれば、レップ数で進む段階もあり、最上段では重量で進むので、「2.5kg足す」という1つのルールでは済みません。
- 下半身は、重量を足さないと進める余地が限られます。シュリンプスクワットやノルディックカールまで来ると、多くの人はバーベルを足して進め続けます。
- 自分に合った最初の段階を見極めるのに、何回か試す必要があります。

## プログラムの構成

- **分割**：毎回全身です。週3回のワークアウトはすべて同じ9種目で、同じものを繰り返しながら、プログレッションの進め方で段階が上がっていきます。
- **ピリオダイゼーション**：レップのダブルプログレッション（5〜8回）に、種目の難易度の段階表を重ねています。週ごとの波も、ディロードもありません。ワークアウトを行い、レップを増やし、レップ範囲の上限に届いたら種目を上げるだけです。
- **スケジュール**：週ごとに固定で、間を1日以上空けた非連続の3日（月・水・金、火・木・土など、都合のよい曜日）に行います。日ごとに分割する設計では*ありません*。毎回全身を行うためのルーティンです。
- **1回の流れ**：ウォームアップ、1組目（懸垂とスクワットの段階）、2組目（ディップスとヒンジ）、3組目（ロウと腕立て伏せ）、最後に体幹の3種目（伸展に耐える、回旋に耐える、伸展を生み出す）です。

## 種目の選び方とその理由

主要6種目は、基本の動作パターンをすべて、複数の関節を使うコンパウンド種目でカバーするように選ばれています。

- **懸垂の段階**（[{Scapular Pull Up}] → [{Arch Hang}] → [{Negative Pull Up}] → [{Pull Up}]）は、垂直方向に引く動作で、広背筋・上背部・上腕二頭筋を使います。初期の段階では、懸垂を1回できるようになる前に必要な、肩甲骨のコントロールとネガティブ動作の筋力を養います。
- **スクワットの段階**（[{Assisted Squat}] → [{Squat, Bodyweight}] → [{Split Squat, Bodyweight}] → [{Bulgarian Split Squat, Bodyweight}] → [{Shrimp Squat}]）は、ひざ主導の下半身の動作です。両脚から片脚へ進めることで、重量を足さずに脚にかかる負荷を段階的に上げます。シュリンプスクワットには初級・中級・上級の3段階があり、そのあとで重量を足します。ピストルスクワットは、wikiが示す別ルートです。
- **ディップスの段階**（[{Support Hold}] → [{Negative Dip}] → [{Chest Dip}]）は、垂直方向に押す動作で、胸・上腕三頭筋・三角筋前部を使います。サポートホールドで上の姿勢を覚えてから、フルのディップスへ下ろしていきます。サポートホールドは60秒まで伸ばしてください。
- **ヒンジの段階**（[{Romanian Deadlift, Bodyweight}] → [{Single Leg Deadlift, Bodyweight}] → [{Nordic Curl, Band}] → [{Nordic Curl}]）は、股関節主導の下半身の動作で、ハムストリングスと大殿筋を使います。ノルディックカールではバンドが体重の一部を支えます。バンドつきのネガティブから始め、次にバンドつきのフルレップ、さらに軽いバンドへと進めることで、自重のハムストリングス種目の中でもとくにきついものへ、無理なく進めます。
- **ロウの段階**（[{Vertical Row}] → [{Incline Row, Bodyweight}] → [{Inverted Row}] → [{Wide Row}]）は、水平方向に引く動作です。ロウはルーティンの土台で、省略できません。押す種目だけでは鍛えにくい背中の中央部を鍛え、肩の健康も保ちます。
- **腕立て伏せの段階**（[{Wall Push Up}] → [{Incline Push Up}] → [{Push Up}] → [{Diamond Push Up}] → [{Pseudo Planche Push Up}]）は、水平方向に押す動作で、胸・上腕三頭筋・三角筋前部に加えて、体幹もかなり使います。

組み合わせにも意図があります。引く動作は必ず脚の動作と（または押す動作はヒンジと）スーパーセットにするので、一方の種目で使う筋肉は、もう一方を行っている間にしっかり休めます。体幹の3種目は、体幹の3つの役割を鍛えます。1つ目は伸展に耐える動作（[{Plank}] → [{Kneeling Ring Ab Rollout}] → [{Ring Ab Rollout}]。リングがなければ[{Ab Wheel}]）、2つ目は回旋に耐える動作（[{Pallof Press}]。別ルートは[{Copenhagen Plank}]）、3つ目は伸展を生み出す動作（[{Reverse Hyperextension, Bodyweight}]。別ルートは[{Back Extension, Bodyweight}]）です。

ウォームアップでは、[{Shoulder Pass Through}]と[{Dead Bug}]を種目として記録します。スクワットのスカイリーチと手首の準備運動も一緒に行ってください。

バーベルとラックがある場合、RRでは、自重の基本を身につけたあとにスクワットとヒンジの段階を、本物の[{Squat}]と[{Romanian Deadlift, Barbell}]・[{Deadlift}]に入れ替えることを勧めています。重量を足すほうが、脚に負荷をかける方法として調整しやすいからです。

## セットとレップの組み方

- **主要6種目**：5〜8回×3セット。新しい種目は5回×3セットから始め、セッションごとにすべてのセットで1回ずつ増やし、フォームを保ったまま8回×3セットに届いたら、次に難しい種目に上がります（また5回×3セットに戻ります）。
- **体幹の3種目**：8〜12回×3セット。進め方は同じダブルプログレッションで、12回×3セットに届いたら次の種目に上がります。パロフプレスとリバースハイパーエクステンションには、次に難しい段階がありません。12回×3セットに届いたら、より強いバンドを使うか、足首にウェイトをつけてください。
- **アイソメトリックのホールド**：アーチハング、サポートホールド、プランクなど一部の段階は、レップ数ではなく時間を計るホールドです。アプリはこれらにセットのタイマーを使います。ホールドを行い、セッションごとに目標が5秒ずつ伸び、30秒（サポートホールドは60秒）に届いたら、次の種目に上がります。
- **強度**：どのセットも、限界の1回手前までで止めます。最初のセットから限界まで追い込むと、あとのセットが崩れます。懸垂の最大が8回なら、8-6-5ではなく7-7-7にします。
- **テンポ**：RRでは10X0のテンポを指定しています。1秒で下ろし、下で止めず、勢いよく上げて、上でも止めません。筋力の多くは、コントロールしたエキセントリック局面で身につきます。

レップ範囲は、筋力とサイズの両方を狙って決められています。難しいコンパウンドの動作での5〜8回は、筋力と筋肥大が重なる範囲で、体幹での8〜12回は、体幹の持久力とコントロールを養います。

## プログレッシブオーバーロード

- **同じ種目の中**：セッションごとに、各セットで1回ずつ増やします（5回×3セット → 6回 → 7回 → 8回）。
- **種目の切り替え**：すべてのセットで8回×3セット（体幹は12回×3セット）を達成したら、その枠の次に難しい種目に上がり、レップ範囲の下限に戻します。
- **段階表の最上段**：載っている中でいちばん難しい種目を使い切ったら、ルーティンは重量を足し始めます。加重懸垂、加重ディップス、加重ロウ、加重シュリンプスクワットです。このアプリでは、最後の段階でレップが上限に届くと、重量を上げ始めます（上半身は2.5kg、下半身は5kg）。
- **停滞したとき**：1回も増やせなければ、次のセッションも同じ数字で繰り返します。あとのセットでレップが大きく落ちる（8回のあとに5〜6回）場合は、種目を下げるのではなく、休憩を長く（最大3分）とります。正式なディロードはありません。自重の疲労は小さいので、ほとんど必要になりません。

## どのくらい続けるか・次は何か

数週間続けて伸びなくなる（食事・睡眠・ストレスを整えたうえで）か、段階表の種目を使い切るまで続けます。多くの初心者では、数か月から1年ほど、順調に伸びます。

その頃には初心者ではなくなり、筋力も筋肉もついています。初心者向けのプログラムには戻らないでください。自重トレーニングを続けたい場合は、中級者向けのカリステニクスのルーティンに進むか、すでに身につけた段階を使って自分で組みます。バーベルでの最大筋力に目標が移るなら、[5/3/1: Boring But Big](/programs/the531bbb)、[Madcow 5x5](/programs/madcow)、[GZCL: The Rippler](/programs/gzcl-the-rippler)のような中級者向けのプログラムに進みます。注意点が1つあります。バーベルの技術は別の技能なので、最初の数回は軽い重量で種目を覚えてください。そのための短い入り口として、[GZCLP](/programs/gzclp)のような初心者向けのリニアプログレッションのプログラムも使えますが、すでに筋肉がついているので数週間で追い抜き、すぐに中級者向けのプログラムに移ることになります。

## 必要な器具

- **ロウに使うバー**：低いバー、体操用リング、頑丈なテーブル、ドアに掛けた結び目つきのシーツでもかまいません。これは必須です。
- **懸垂バー**：懸垂の段階に進んだら必要です（うんてい、ドア用のバー、リングなど）。
- **ディップス用の平行棒**：頑丈な椅子2脚、キッチンカウンターの角、リングでも代用できます。リングディップスも有効な別ルートです。
- **バンド**：肩のウォームアップ、パロフプレス、バンドつきのノルディックカールに使います。
- **ベンチ、ボックス、頑丈な縁**：リバースハイパーエクステンションに使います。
- **体操用リング**：プランクを卒業したあとのアブローラーに使います（アブホイールでもかまいません）。
- **ダンベル2個またはウェイトベスト**：始めるときは不要ですが、自重では足りなくなったときに、各段階表の最上段で負荷をかけるのに使います（加重懸垂、ディップス、ロウ、シュリンプスクワット）。
- 始めるのに、ほかに必要なものはありません。初期の段階はすべて純粋な自重です。

## 休憩時間

- **組み合わせた種目の間**：90秒です。組になった2種目を交互に行うので、それぞれの種目では、セット間に約3分の休憩がとれます。ほぼ完全に回復できる時間です。
- **体幹の3種目**：種目の間は60秒です（90秒まで延ばしても、時間を節約して30〜45秒に縮めてもかまいません）。
- レップが大きく落ちるときは、休憩を最大3分まで延ばします。ワークアウトの速さより、レップの質のほうが大切です。

## 開始重量の決め方

選ぶ重量はなく、代わりに**最初の段階**を選びます。9つの枠それぞれについて、段階表の上から順に試し、きれいに5回×3セット（体幹は8回×3セット）できるいちばん難しい種目に決めてください。枠によって、4段目から始める枠と1段目から始める枠が混ざるのは普通です。

よくある失敗は、難しすぎる段階から始めることです。レップが崩れる（8回、次に5回、次に3回）ようなら、易しい段階に下げます。最初のセッションは、簡単すぎると感じるくらいの種目を選んでください。どのみち1〜2週間で次に進めます。

## よくあるアレンジ

- **ボリュームが多すぎる**：種目ごとに1〜2セットに減らして徐々に増やすか、週2日にします。
- **平行棒がない**：リングディップスのルートを使うか、別の押す種目の段階に置き換えます。
- **まだ懸垂バーがない**：バーが使えるようになるまで、ロウと、肩甲骨まわり・アーチハングの種目を続けます。
- **バーベルがある**：動作を覚えたら、スクワットの段階をバックスクワットに、ヒンジの段階をルーマニアンデッドリフト（1回目と3回目のワークアウト）とデッドリフト（2回目のワークアウト）に置き換えます。
- **もっとやりたい**：メインのワークアウトを長くするのではなく、休みの日にスキル練習（逆立ち、Lシット）やモビリティを足します。

### 推奨ルーティンは初心者に向いていますか？

はい。トレーニングを始めたばかりの人の最初のプログラムとして作られています。最初の段階（補助つきスクワット、壁腕立て、垂直ロウ）は、基礎の筋力がなくてもでき、筋力がつくにつれて、プログレッションの仕組みが難易度を自動で上げます。カリステニクス全体でも、とくによく勧められる出発点の1つです。

### 推奨ルーティンは週に何日ですか？

週3日で、ワークアウトの間に休みを1日以上空けます（例：月・水・金）。どの回も同じ全身のワークアウトです。もっと多くの日に分割しないでください。毎回全身で行うように作られていて、休みの日にこそ筋力が伸びます。

### プログレッションはどう進みますか？

9つの種目の枠はそれぞれ、易しい種目から難しい種目へ並んだ段階表です。5回×3セットでできるいちばん難しい種目を選び、セッションごとに各セットで1回ずつ増やし、フォームを保ったまま8回×3セットできたら、次の種目に上がって、また5回×3セットから始めます。体幹の種目は8〜12回×3セットです。1回のセッションで、1つの枠につき行う種目は1つだけです。

### 推奨ルーティンにはどんな器具が必要ですか？

最低限、下にもぐって引ける水平なもの（低いバー、リング、頑丈なテーブル）が必要です。ロウは省略も代用もできません。できれば、懸垂バー、平行棒（または椅子）、パロフプレス用のバンド、リバースハイパーエクステンション用のベンチもあるとよいです。それ以外はすべて自重です。

### 推奨ルーティンはどのくらい続けるべきですか？

食事と回復を整えたうえで数週間伸びなくなるか、段階表を使い切るまでです。初心者なら、通常は数か月から1年ほどです。そのあとは、目標に応じて、中級者向けの自重ルーティンかバーベルのプログラムに進みます。

### 推奨ルーティンは毎日できますか？

できません。週3回のルーティンとして意図的に作られています。筋力と筋肉は、トレーニング中ではなく、回復している間につきます。毎日行うと回復が追いつかず、伸びが遅くなります。休みの日にやりたいことがあるなら、スキル練習やモビリティにしてください。

### 腕と肩の種目はありませんか？

すでに入っています。懸垂とロウでは、握って引くことで上腕二頭筋と前腕が強く働き、ディップスと腕立て伏せでは、上腕三頭筋と三角筋前部が強く刺激されます。どの種目もコンパウンドなので、アイソレーションを入れなくても、腕と肩に十分な刺激が入ります。あとから腕のアイソレーション種目を足してもかまいませんが、成長に必須ではありません。

### プランクやサポートホールドのようなアイソメトリックのホールドはどう扱いますか？

アプリは時間を計るセットとして扱います。ホールドしている間、セットのタイマーが動くので、レップ数は数えません。セッションごとに目標が5秒ずつ伸び、3セットすべてで30秒（サポートホールドは60秒）のホールドができたら、プログラムが自動的に、その枠の次に難しい種目に進めます。

        exerciseVariationIndex += 1
        reps = state.minReps
      } else if (state.addWeight > 0lb) {
        weights += state.addWeight
        reps = state.minReps
      }
    } else {
      reps += 1
    }
  }
~}

/// Ladders that contain a timed isometric hold. Set variation 1 = timed hold, set variation 2 = reps;
/// `holdRung` is which movement in the ladder is the hold. On the hold you add 5s each session until the
/// holdTarget (then graduate); on the rep rungs you add a rep. The set scheme flips when you cross the hold.
rrHold / used: none / 3x1 0lb 20s|60s / 3x8 0lb 60s / warmup: none / progress: custom(topVar: 4, holdRung: 2, holdTarget: 30, minReps: 5, maxReps: 8, addWeight: 5lb) {~
  if (exerciseVariationIndex == state.holdRung) {
    setVariationIndex = 1
    if (completedSetTime >= setTime) {
      if (setTime >= state.holdTarget && exerciseVariationIndex < state.topVar) {
        exerciseVariationIndex += 1
        setVariationIndex = 2
      } else {
        setTime[*:*:1:*] += 5
      }
    }
  } else {
    setVariationIndex = 2
    if (completedReps >= reps) {
      if (reps >= state.maxReps) {
        if (exerciseVariationIndex < state.topVar) {
          var.next = exerciseVariationIndex + 1
          exerciseVariationIndex = var.next
          setVariationIndex = var.next == state.holdRung ? 1 : 2
          reps[*:*:2:*] = state.minReps
        } else if (state.addWeight > 0lb) {
          weights += state.addWeight
          reps[*:*:2:*] = state.minReps
        }
      } else {
        reps[*:*:2:*] += 1
      }
    }
  }
~}
